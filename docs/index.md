# The Elite Engineer

A project-driven training system for **job readiness** (Python, FastAPI, PHP, Moodle), **full-stack depth**, **modern C++** and **quantitative development**, with a no-AI independence protocol running through all of it.

Reading is not mastery. Every lesson ends in a deliverable and a mastery gate (80/100, no critical failure). Set each lesson's ledger status honestly; it is saved in this browser only.
