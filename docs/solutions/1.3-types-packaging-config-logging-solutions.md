## Section 7: Retrieval answers

1. At runtime Python returns `1` (an `int`), no error: annotations are not enforced. mypy reports `Incompatible return value type (got "int", expected "str")`.
2. Type checkers do flow-sensitive narrowing: inside the `if row is None:` branch the type is `None`; the branch raises, so after it `row` can only be the non-`None` member of the union and attribute/item access type-checks.
3. `Protocol`: a function needs "anything with a `now()` method" and you want fakes in tests without inheritance; also for third-party classes you cannot modify. ABC: you want shared implementation, explicit registration, or `isinstance` checks as part of the design (and want a clear error when a subclass forgets an abstract method at instantiation time).
4. A mutable default is shared by every instance; dataclasses refuse it at class creation: `ValueError: mutable default <class 'list'> for field xs is not allowed: use default_factory`. Fix: `xs: list[int] = field(default_factory=list)`.
5. With `eq=True` (default) and `frozen=True`, dataclass generates `__hash__` from the fields. Frozen instances cannot change after insertion into a set/dict, which preserves the "hash must not change" half of the contract (Lesson 1.1). With `eq=True` and not frozen, `__hash__` is set to `None` (unhashable).
6. The import system caches the module object in `sys.modules`; later imports return it without re-executing the code. Consequences: import-time side effects (reading config, opening connections) happen once and at an unpredictable time relative to test setup; module-level state is a process-wide singleton, shared across requests.
7. Running a file by path puts that file's directory (`src/billing`) first in `sys.path`. `import logging` finds `src/billing/logging.py` before the standard library. Fix: run with `python -m billing.cli`/console script and do not name modules after stdlib modules.
8. `a` starts importing, runs `import b`; `b` runs `from a import X` but `a` is only partially initialised in `sys.modules` (X not yet defined): `ImportError: cannot import name 'X' from partially initialized module 'a'`. Fixes: (1) extract the shared definitions into a third module both import; (2) import locally inside the function that needs it; (3) for type-only needs, `if TYPE_CHECKING:` import.
9. `uv sync --locked` installs exactly the lockfile and errors if the lockfile no longer matches `pyproject.toml`. `--frozen` installs the lockfile without checking it is current (use deliberately, for example when the lock is known good and you do not want a resolver). `pip freeze > requirements.txt` captures the currently installed set of the environment (including unrelated packages), without hashes or the dependency graph, and tied to the platform; it is a snapshot, not a controlled lock.
10. Read once at startup (the entry point), into an immutable settings object that is passed down. Accepting a `Mapping` lets tests supply a dict without mutating the process environment, and lets you validate arbitrary sources.
11. Because `basicConfig` is a no-op when the root logger already has handlers (and module-level `logging.info`/`warning` helpers call it implicitly the first time). Avoid by configuring once, first, with `dictConfig` (or `basicConfig(force=True)` in scripts), and by banning module-level logging calls before configuration and `basicConfig` in libraries.
12. `log.exception("failed", extra={"user": user})` or `log.exception("failed user=%s", user)`. The original: (a) logs `e` text only, not the traceback if used with `error` (and `exception` adds it automatically), (b) f-string formatting is eager and defeats grouping by message template and lazy evaluation, and mixes data into the message so it is not a searchable field.

## Section 8: Challenge reference solution

```python
# retry_config.py
from __future__ import annotations

import math
import random
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Protocol


class ConfigError(Exception):
    def __init__(self, problems: list[str]) -> None:
        super().__init__("; ".join(problems))
        self.problems = problems


class Sleeper(Protocol):
    def sleep(self, seconds: float) -> None: ...


@dataclass(frozen=True, slots=True)
class RetryPolicy:
    max_attempts: int = 3
    base_delay_s: float = 0.5
    max_delay_s: float = 30.0
    jitter: bool = True

    def __post_init__(self) -> None:
        problems = _check(self.max_attempts, self.base_delay_s, self.max_delay_s)
        if problems:
            raise ConfigError(problems)

    @classmethod
    def from_env(cls, env: Mapping[str, str], prefix: str = "RETRY_") -> RetryPolicy:
        problems: list[str] = []
        default = cls()
        attempts, base, cap, jitter = (default.max_attempts, default.base_delay_s,
                                       default.max_delay_s, default.jitter)
        name = f"{prefix}MAX_ATTEMPTS"
        if name in env:
            try:
                attempts = int(env[name])
            except ValueError:
                problems.append(f"{name} must be an integer")
        for var, attr in (("BASE_DELAY_S", "base"), ("MAX_DELAY_S", "cap")):
            full = prefix + var
            if full in env:
                try:
                    value = float(env[full])
                    if not math.isfinite(value):
                        raise ValueError
                except ValueError:
                    problems.append(f"{full} must be a finite number")
                    continue
                if attr == "base":
                    base = value
                else:
                    cap = value
        name = f"{prefix}JITTER"
        if name in env:
            text = env[name].strip().lower()
            if text in {"true", "1"}:
                jitter = True
            elif text in {"false", "0"}:
                jitter = False
            else:
                problems.append(f"{name} must be true/false/1/0")
        if not problems:
            problems = _check(attempts, base, cap)
        if problems:
            raise ConfigError(problems)
        return cls(attempts, base, cap, jitter)


def _check(attempts: int, base: float, cap: float) -> list[str]:
    problems = []
    if attempts < 1:
        problems.append("max_attempts must be >= 1")
    if base <= 0 or cap <= 0:
        problems.append("delays must be > 0")
    if base > cap:
        problems.append("base_delay_s must be <= max_delay_s")
    return problems


def delays(policy: RetryPolicy, rng: random.Random) -> list[float]:
    """Delays before retry 1..max_attempts-1 (the first attempt has no delay)."""
    out: list[float] = []
    for attempt in range(policy.max_attempts - 1):
        value = min(policy.max_delay_s, policy.base_delay_s * 2**attempt)
        out.append(rng.uniform(0, value) if policy.jitter else value)
    return out
```

```python
# test_retry_config.py
import random
import pytest
from retry_config import ConfigError, RetryPolicy, delays

def test_defaults():
    assert RetryPolicy.from_env({}) == RetryPolicy()

def test_each_invalid():
    for var, bad in [("RETRY_MAX_ATTEMPTS", "0"), ("RETRY_MAX_ATTEMPTS", "x"), ("RETRY_BASE_DELAY_S", "nan"),
                     ("RETRY_BASE_DELAY_S", "-1"), ("RETRY_JITTER", "maybe")]:
        with pytest.raises(ConfigError) as ei:
            RetryPolicy.from_env({var: bad})
        assert ei.value.problems

def test_multiple_reported():
    with pytest.raises(ConfigError) as ei:
        RetryPolicy.from_env({"RETRY_MAX_ATTEMPTS": "x", "RETRY_JITTER": "maybe", "RETRY_BASE_DELAY_S": "inf"})
    assert len(ei.value.problems) == 3

def test_jitter_false_string():
    assert RetryPolicy.from_env({"RETRY_JITTER": "false"}).jitter is False

def test_delays_no_jitter_capped():
    p = RetryPolicy(max_attempts=6, base_delay_s=1, max_delay_s=5, jitter=False)
    assert delays(p, random.Random(0)) == [1, 2, 4, 5, 5]

def test_delays_deterministic_with_seed_and_bounded():
    p = RetryPolicy(max_attempts=4, base_delay_s=1, max_delay_s=5, jitter=True)
    a, b = delays(p, random.Random(0)), delays(p, random.Random(0))
    assert a == b and all(0 <= x <= lim for x, lim in zip(a, [1, 2, 4]))

def test_frozen_and_base_gt_cap():
    p = RetryPolicy()
    with pytest.raises(Exception):
        p.max_attempts = 9  # type: ignore[misc]
    with pytest.raises(ConfigError):
        RetryPolicy(base_delay_s=10, max_delay_s=1)
```

Notes: `from_env` constructs the instance only after collecting every problem, so the multiple-errors test sees all three at once. Validation lives in `__post_init__` as well so direct construction is checked too (`_check` is shared). `delays` takes an injected `random.Random`, making jitter deterministic. The `Sleeper` protocol is declared as required by the spec and would be consumed by a retry loop (Lesson 2.6). Trade-off: reading defaults from `cls()` ties defaults to the dataclass; alternative is module constants. Alternative design: Pydantic `BaseSettings` (Lesson 2.2) gives env parsing for free, at the cost of a dependency and less transparent error aggregation.

```python
# billing/src/billing/config.py
from __future__ import annotations

import math
import os
from collections.abc import Mapping
from dataclasses import dataclass, field
from typing import Literal, cast, get_args

Environment = Literal["dev", "staging", "prod"]
_LEVELS = {"DEBUG", "INFO", "WARNING", "ERROR", "CRITICAL"}
_TRUE = {"true", "1"}
_FALSE = {"false", "0"}          # "yes"/"no" deliberately NOT accepted: see DECISIONS.md


class ConfigError(Exception):
    """Invalid configuration. `problems` lists variable names and rules, never secret values."""

    def __init__(self, problems: list[str]) -> None:
        super().__init__("; ".join(problems))
        self.problems = problems


@dataclass(frozen=True, slots=True)
class Settings:
    database_url: str = field(repr=False)
    environment: Environment = "dev"
    log_level: str = "INFO"
    http_timeout_s: float = 5.0
    worker_count: int = 1
    debug: bool = False

    @classmethod
    def from_env(cls, env: Mapping[str, str] | None = None) -> Settings:
        env = os.environ if env is None else env
        problems: list[str] = []

        def raw(name: str, default: str | None = None) -> str | None:
            value = env.get(name)
            value = default if value is None else value.strip()
            if value is None or value == "":
                if default is None:
                    problems.append(f"{name} is required")
                    return None
                return default
            return value

        db = raw("APP_DATABASE_URL")

        environment = (raw("APP_ENVIRONMENT", "dev") or "dev").lower()
        if environment not in get_args(Environment):
            problems.append(f"APP_ENVIRONMENT must be one of {list(get_args(Environment))}")

        level = (raw("APP_LOG_LEVEL", "INFO") or "INFO").upper()
        if level not in _LEVELS:
            problems.append(f"APP_LOG_LEVEL must be one of {sorted(_LEVELS)}")

        timeout = 0.0
        try:
            timeout = float(raw("APP_HTTP_TIMEOUT_S", "5") or "5")
            if not math.isfinite(timeout) or timeout <= 0:
                raise ValueError
        except ValueError:
            problems.append("APP_HTTP_TIMEOUT_S must be a finite number > 0")

        workers = 1
        try:
            workers = int(raw("APP_WORKER_COUNT", "1") or "1")
            if not 1 <= workers <= 64:
                raise ValueError
        except ValueError:
            problems.append("APP_WORKER_COUNT must be an integer in 1..64")

        flag = (raw("APP_DEBUG", "false") or "false").lower()
        if flag not in _TRUE | _FALSE:
            problems.append("APP_DEBUG must be one of true/false/1/0")

        if problems or db is None:
            raise ConfigError(problems)
        return cls(db, cast(Environment, environment), level, timeout, workers, flag in _TRUE)
```

```python
# billing/src/billing/logging_setup.py
from __future__ import annotations

import contextvars
import json
import logging
import logging.config
import sys
from typing import IO, Any

request_id: contextvars.ContextVar[str] = contextvars.ContextVar("request_id", default="-")


class RequestIdFilter(logging.Filter):
    def filter(self, record: logging.LogRecord) -> bool:
        record.request_id = request_id.get()
        return True


_STANDARD = set(logging.makeLogRecord({}).__dict__) | {"message", "asctime"}


class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        payload: dict[str, Any] = {
            "ts": self.formatTime(record, "%Y-%m-%dT%H:%M:%S%z"),
            "level": record.levelname,
            "logger": record.name,
            "msg": record.getMessage(),
        }
        payload.update({k: v for k, v in record.__dict__.items() if k not in _STANDARD})
        if record.exc_info:
            payload["exc"] = self.formatException(record.exc_info)
        return json.dumps(payload, default=str, ensure_ascii=False)


def configure_logging(level: str, stream: IO[str] | None = None) -> None:
    """Call once at the entry point. Safe to call again: dictConfig replaces the root handlers."""
    logging.config.dictConfig({
        "version": 1,
        "disable_existing_loggers": False,
        "filters": {"rid": {"()": RequestIdFilter}},
        "formatters": {"json": {"()": JsonFormatter}},
        "handlers": {"out": {"class": "logging.StreamHandler",
                              "stream": stream if stream is not None else sys.stdout,
                              "formatter": "json", "filters": ["rid"]}},
        "root": {"level": level, "handlers": ["out"]},
    })
```

```python
from __future__ import annotations

from datetime import UTC, datetime
from typing import Protocol


class Clock(Protocol):
    def now(self) -> datetime: ...


class SystemClock:
    def now(self) -> datetime:
        return datetime.now(UTC)
```

```python
# billing/src/billing/cli.py
from __future__ import annotations

import logging
import sys
import uuid
from collections.abc import Mapping, Sequence

from .clock import Clock, SystemClock
from .config import ConfigError, Settings
from .logging_setup import configure_logging, request_id

log = logging.getLogger("billing.cli")


def main(argv: Sequence[str] | None = None, env: Mapping[str, str] | None = None,
         clock: Clock | None = None) -> int:
    """Return 0 on success, 2 on configuration error."""
    clock = clock or SystemClock()
    try:
        settings = Settings.from_env(env)
    except ConfigError as exc:
        sys.stderr.write("configuration error:\n" + "\n".join(f"  - {p}" for p in exc.problems) + "\n")
        return 2
    configure_logging(settings.log_level)
    request_id.set(uuid.uuid4().hex[:8])
    log.info("worker starting", extra={
        "started_at": clock.now().isoformat(),
        "environment": settings.environment,
        "worker_count": settings.worker_count,
        "http_timeout_s": settings.http_timeout_s,
        "debug": settings.debug,
    })
    return 0
```

### DECISIONS.md (reference content)

- **Tools.** uv for locking and running, because it was available and fast; the same `pyproject.toml` works with `pip install -e . --group dev` on recent pip (VERIFY the `--group` flag in your pip version) or `pip install -e .` plus `pip install pytest mypy`. If the team uses another tool, adopt theirs.
- **Booleans.** Accept `true/false/1/0`, case-insensitive. `yes/no/on/off` rejected to keep one documented vocabulary; a rejected value is a loud startup error rather than a silent default.
- **Empty vs unset.** Whitespace is stripped and an empty value is treated as unset: required variables then report "is required", optional ones use their defaults. A debatable choice; the alternative (empty string is invalid) is stricter.
- **Secrets.** `database_url` is excluded from `repr`, never included in `ConfigError` text (messages contain variable names and rules only), never logged. Limits: the value still sits in the process environment and in memory; anyone who can read `/proc/<pid>/environ` or core dumps can see it.
- **Why env, not file.** 12-factor; container platforms inject env; no secrets in the repo. The extension challenge adds `*_FILE` support for mounted secrets.
- **Exit codes.** 0 success, 2 configuration error (conventionally "usage/config error"); a convention you document, not a standard.
- **Known test hygiene gap.** `configure_logging` mutates global logging state, so tests leave a root handler behind. Lesson 1.4 fixes this with a fixture that restores handlers; for now `test_logging_lines...` configures explicitly each time.

### Rubric scoring notes

- Reproducibility (20): 10 for a transcript from an empty directory with real output, 5 for a lockfile that is current, 5 for `.gitignore`/`.env.example`.
- Settings (20): deduct 3 per missing edge case from the list; secret in `repr` is a critical failure.
- Logging (20): JSON parse test, request id, double-configure test, no f-strings in log calls.
- Types (15): `Protocol` used for something the tests fake (`Clock`); each `cast` justified (`cast(Environment, ...)` is justified by the preceding membership check).
- Common mistakes seen: forgetting `float("nan")` passes `float()` and `> 0` is `False` for `nan` only by accident of comparison semantics (`nan <= 0` is `False`, so `not (timeout > 0)` is needed or an `isfinite` check), reading `os.environ` in `logging_setup`, calling `basicConfig` in a library module.

### Alternatives

- `pydantic-settings` (Lesson 2.2) for env parsing and validation: less code, richer errors, a dependency and different error format.
- `python -m venv` + `pip-tools` (`pip-compile --generate-hashes`) as a lockfile approach; the concepts (ranges in source of truth, exact pins plus hashes generated, `--require-hashes` at install) are identical.
- `structlog` for logging; decide with the team.
