Attempt the lesson first. All code here was run with FastAPI 0.162.0, Pydantic 2.14.1, Starlette 1.10.0, Python 3.13, pytest 9.1.1 (19 tests in the final reference suite, all passing).

## Section 7: Retrieval practice answers

1. `scope` (dict describing the connection: type `http`/`websocket`/`lifespan`, path, headers), `receive` (awaitable yielding incoming events such as request body chunks), `send` (awaitable emitting `http.response.start` with status and headers, then `http.response.body`). The ASGI server (Uvicorn) owns the socket and HTTP parsing.
2. `task_id`: path parameter (name appears in the path template). `q`: query parameter (scalar, not in path, optional). `body`: JSON request body (Pydantic model).
3. `strict=True` disables coercion: `"7"` and `True` are rejected for `int`. Default (lax): `"7"` becomes `7`; `true` becomes `1` in lax mode (observed here with an `int` field). Checked on Pydantic 2.14.1: both Python `True` and JSON `true` give `1` for `int` in lax mode; the conversion table in the Pydantic docs lists where JSON-mode and Python-mode differ.
4. `exclude_unset=True` returns only fields the client supplied, separating "omitted" (leave alone) from "null" (explicit value). `exclude_none=True` drops explicit nulls too, so a client can never clear a nullable field, and it hides the null-on-non-nullable error.
5. Default `extra="ignore"`: unknown fields are silently dropped. `forbid` turns client typos and mass-assignment attempts (`is_admin`) into 422s.
6. Request validation (incl. dependency resolution) -> your path function -> `response_model` filtering/serialization -> response middleware -> response sent -> default-scope `yield` dependency exit code.
7. The client has already received its response, so the exception cannot change it; it is logged (and may be surfaced as a server error log) but the client sees 200. This is why committing in post-`yield` code under the default scope is dangerous (Lesson 2.4 lab). With `scope="function"` the exit code runs before the response is sent.
8. `app.dependency_overrides[get_store] = lambda: store` and, in teardown, `app.dependency_overrides.clear()`.
9. The router raises Starlette's `HTTPException` for unknown routes and 405. FastAPI's `HTTPException` subclasses Starlette's, so a handler for Starlette's class catches both; a handler registered only for FastAPI's would miss router-generated ones.
10. `def` when the function does any blocking I/O or CPU work (sync DB driver, `requests`, file reads): FastAPI runs it in a threadpool. `async def` only when everything awaited is async. Wrong choice (blocking call in `async def`) stalls the event loop, so all concurrent requests freeze while single-request tests look fine.
11. `GET /tasks/me` matches `/{task_id}` first (registration order), tries to parse `"me"` as int, and returns 422. Register static paths before parameterized ones.
12. With `with`, the app's lifespan startup and shutdown run (observed: events `['start', 'stop']`); without it they do not run, so anything created in lifespan (pools, `app.state`) is missing. The Starlette TestClient docs describe lifespan handling via `with`, and `raise_server_exceptions` (default `True`) re-raises server errors into the test.

## Section 8: Challenge reference solution

Changes against the lesson code:

1. **PATCH nulls** (`schemas.py`): a `model_validator(mode="after")` inspects `model_fields_set` (the set of fields actually provided) and rejects any that are `None`.

```python
class TaskPatch(BaseModel):
    model_config = ConfigDict(extra="forbid")
    title: Title | None = None
    priority: int | None = Field(default=None, ge=1, le=5)
    done: bool | None = None

    @model_validator(mode="after")
    def no_explicit_nulls(self) -> "TaskPatch":
        for name in self.model_fields_set:
            if getattr(self, name) is None:
                raise ValueError(f"{name} may not be null")
        return self
```

   Alternative: declare the fields non-nullable with a sentinel default (`UNSET`) and handle serialization manually. More precise types, more machinery; the validator is the simpler design. Note the error `loc` for a model-level validator is `["body"]`, not the field; if you want the field in `loc`, use a `field_validator` per field with `ValidationInfo`, or raise `PydanticCustomError` per field. Mention this trade-off in review.

2. **Sort**: `SortKey = Literal["created", "-created", "priority", "-priority"]` in the query signature (invalid values are 422 automatically). Store sorts by `id` first, then by priority with Python's stable sort, so ties keep id order.
3. **Request id, unhandled exception, complete Allow**: `app/errors.py`.

```python
import logging
import re
import uuid

from fastapi import FastAPI, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException
from starlette.types import ASGIApp, Message, Receive, Scope, Send

log = logging.getLogger("app")


class TaskNotFound(Exception):
    def __init__(self, task_id: int) -> None:
        self.task_id = task_id


class RequestIdMiddleware:
    """Pure ASGI middleware: read or create X-Request-ID, expose it, echo it."""

    def __init__(self, app: ASGIApp) -> None:
        self.app = app

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http":
            return await self.app(scope, receive, send)
        headers = dict(scope["headers"])
        rid = headers.get(b"x-request-id", b"").decode("latin-1")[:64] or uuid.uuid4().hex
        scope.setdefault("state", {})["request_id"] = rid

        async def send_with_id(message: Message) -> None:
            if message["type"] == "http.response.start":
                message.setdefault("headers", []).append((b"x-request-id", rid.encode("latin-1")))
            await send(message)

        await self.app(scope, receive, send_with_id)


def _problem(request: Request, status: int, title: str, detail: str | None = None, **extra):
    body = {"type": "about:blank", "title": title, "status": status,
            "instance": request.url.path,
            "request_id": getattr(request.state, "request_id", None)}
    if detail:
        body["detail"] = detail
    body.update(extra)
    return JSONResponse(body, status_code=status, media_type="application/problem+json")


def allowed_methods(request: Request) -> str:
    """Complete Allow value from the public OpenAPI schema (path templates -> methods).

    Why not walk app.router.routes? In FastAPI 0.162 included routers are wrapped in a private
    structure, so the route list is not a stable public surface (an internal detail of this version; re-check if you upgrade).
    """
    methods: set[str] = set()
    for template, ops in request.app.openapi()["paths"].items():
        pattern = "^" + re.sub(r"\{[^/]+\}", "[^/]+", template) + "$"
        if re.match(pattern, request.url.path):
            methods |= {m.upper() for m in ops}
    if "GET" in methods:
        methods.add("HEAD")
    return ", ".join(sorted(methods))


def install_error_handlers(app: FastAPI) -> None:
    @app.exception_handler(TaskNotFound)
    async def _not_found(request: Request, exc: TaskNotFound):
        return _problem(request, 404, "Task not found", f"No task with id {exc.task_id}")

    @app.exception_handler(RequestValidationError)
    async def _invalid(request: Request, exc: RequestValidationError):
        errors = [{"loc": list(e["loc"]), "msg": e["msg"], "type": e["type"]} for e in exc.errors()]
        return _problem(request, 422, "Validation failed", errors=errors)

    @app.exception_handler(StarletteHTTPException)
    async def _http(request: Request, exc: StarletteHTTPException):
        resp = _problem(request, exc.status_code, str(exc.detail))
        if exc.status_code == 405:
            resp.headers["Allow"] = allowed_methods(request)
        elif exc.headers:
            resp.headers.update(exc.headers)
        return resp

    @app.exception_handler(Exception)
    async def _unhandled(request: Request, exc: Exception):
        log.exception("unhandled error request_id=%s", getattr(request.state, "request_id", None))
        resp = _problem(request, 500, "Internal Server Error")   # no detail: never leak internals
        resp.headers["X-Request-ID"] = getattr(request.state, "request_id", "")
        return resp
```

   `main.py` adds `app.add_middleware(RequestIdMiddleware)` after `install_error_handlers(app)`. Design notes: the middleware is *pure ASGI* rather than `BaseHTTPMiddleware`, which avoids that class's known awkwardness with streaming and context propagation (the Starlette middleware docs state that `BaseHTTPMiddleware` prevents `ContextVar` changes from propagating upwards and can disrupt contextvars for later pure ASGI middleware; checked). The generic `Exception` handler is run by Starlette's outermost `ServerErrorMiddleware`, outside your middleware, so it must add the `X-Request-ID` header itself (it reads the id from `request.state`, set by your middleware earlier in the same scope). Client-supplied ids are truncated to 64 chars; in production also restrict the charset before logging (log injection).

   The `Allow` computation uses `app.openapi()["paths"]` because in FastAPI 0.162 `app.router.routes` contains a private `_IncludedRouter` wrapper rather than flat `APIRoute`s (observed). Walking private structures is fragile; the OpenAPI document is public and is already the contract. Cost: `app.openapi()` is cached after first generation. The default framework-generated `Allow` listed only one method in this environment.

from fastapi.testclient import TestClient

from app.deps import get_store

def make(client, **kw):

@pytest.mark.parametrize("field", ["title", "priority", "done"])

    assert r.json()["errors"][0]["loc"][0] == "body"

    assert client.patch(f"/tasks/{t['id']}", json={"done": True}).json()["title"] == "t"


def test_sort_priority_with_tiebreaker(client):
    for p in (3, 1, 3, 2):
        make(client, priority=p)
    ids = lambda q: [i["id"] for i in client.get("/tasks", params=q).json()["items"]]
    assert ids({"sort": "priority"}) == [2, 4, 1, 3]
    assert ids({"sort": "-created"}) == [4, 3, 2, 1]
    assert client.get("/tasks", params={"sort": "nope"}).status_code == 422


def test_request_id_supplied_and_generated(client):
    r = client.get("/tasks/999", headers={"X-Request-ID": "abc-123"})

    r = client.get("/tasks/999")
    assert len(r.headers["x-request-id"]) == 32 and r.json()["request_id"] == r.headers["x-request-id"]


def test_unhandled_exception_does_not_leak(client_no_raise):
    @app.get("/boom")
    def boom():
        raise RuntimeError("secret")
    try:
        r = client_no_raise.get("/boom")
    finally:
        app.router.routes.pop()
    assert r.status_code == 500 and "secret" not in r.text
    assert r.headers["content-type"].startswith("application/problem+json")


def test_overrides_do_not_leak_between_tests_a(client):

## Section 9: Project reference approach

Key design decisions (a complete solution is a day of work; these are the parts people get wrong).

**Schemas** (verified):

```python
from typing import Annotated
from pydantic import BaseModel, ConfigDict, Field, HttpUrl, StringConstraints, field_validator

Tag = Annotated[str, StringConstraints(strip_whitespace=True, to_lower=True, min_length=1, max_length=30)]


class BookmarkCreate(BaseModel):
    model_config = ConfigDict(extra="forbid")
    url: HttpUrl
    title: Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=200)]
    tags: list[Tag] = Field(default_factory=list, max_length=10)
    note: str | None = Field(default=None, max_length=2000)

    @field_validator("tags")
    @classmethod
    def dedupe(cls, v: list[str]) -> list[str]:
        return list(dict.fromkeys(v))          # order-preserving dedupe, after normalization


if __name__ == "__main__":
    b = BookmarkCreate(url="https://example.com/a b", title="  T ", tags=[" Py ", "py", "API"])
    print(b.model_dump(mode="json"))
    for bad in ({"url": "ftp://x.com", "title": "t"}, {"url": "https://x.com", "title": "t", "tags": ["a"]*11}):
        try: BookmarkCreate(**bad)
        except Exception as e: print(type(e).__name__, e.errors()[0]["type"])
```

Observed output for `url="https://example.com/a b"`, title `"  T "`, tags `[" Py ", "py", "API"]`: URL normalized with `%20`, title trimmed to `T`, tags `['py', 'api']` (normalization happens before the dedupe validator runs). `ftp://x.com` fails with `url_scheme`; 11 tags fails with `too_long`. `HttpUrl` normalizes URLs (observable in output), so decide whether you store the normalized or the original string and put it in DECISIONS.md.

**Store**: methods take `user: str` as a mandatory first argument and key rows by `(user, id)`; a lookup for another user's bookmark returns `None`, which the router turns into 404. The mid-way change then costs one dependency: `def current_user(x_user: Annotated[str, Header(min_length=1, max_length=64)]) -> str: return x_user.strip().lower()`. Missing header gives 422 by default; many teams prefer 401. State your choice (this placeholder is replaced in Lesson 2.5).

**Search**: `q` is a case-insensitive substring on title; reject `q` longer than 100 chars; treat empty `q` as absent or 422 consistently and test it.

**OpenAPI snapshot**: script `python -c "import json; from app.main import app; print(json.dumps(app.openapi(), indent=2, sort_keys=True))" > openapi.json`, and a test:

**Rubric scoring notes.** HTTP semantics (20): full marks need Location on 201, 204 without body, documented repeat-DELETE, and 422 versus 400 chosen and consistent (remember FastAPI returns 422 `json_invalid` for malformed JSON by default; either accept and document or override). Validation (20): deduct for `extra` left as ignore without reason, for lax coercion on counts or money without a decision, and for tag normalization done in routes. PATCH (10): all-or-nothing on explicit null handling. DI and isolation (15): override cleared in teardown; tests pass reordered. Errors (10): unhandled-exception test must exist. Mid-way change (5): if the learner had to edit every route signature, they did not use a shared dependency alias. Critical: any endpoint returning another user's bookmark.

Alternatives worth discussing in review: class-based dependencies (`Pagination`) versus a function returning a dataclass; `Annotated` aliases versus repeating `Depends` in each signature; returning ORM or dataclass instances and relying on `response_model` versus building output models explicitly (the explicit version fails earlier and is easier to read in a stack trace).
