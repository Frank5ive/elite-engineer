## Section 8.A: Derivations

D1. Write x_i - xbar = (x_i - mu) - (xbar - mu). Sum of squares = sum (x_i - mu)^2 - n (xbar - mu)^2. Expectation: n sigma^2 - n (sigma^2/n) = (n-1) sigma^2. Divide by n-1.
D2. S = sum (y_i - a - b x_i)^2. dS/da: sum(y - a - bx) = 0, so a = ybar - b xbar. dS/db: sum x(y - a - bx) = 0. Substitute a: sum x_i y_i - n xbar ybar = b (sum x_i^2 - n xbar^2), so b = Cov(x,y)/Var(x) (matching divisors).
D3. The normal equations X^T (y - Xb) = 0 say X^T r = 0, i.e. r is orthogonal to every column. Measured max |X^T r| about 6e-14 (rounding).
D4. Cov(x_s, x_t) = phi^|s-t| / (1 - phi^2). Sum over all pairs is approximately n (1/(1-phi^2)) (1 + 2 sum_{k>=1} phi^k) = n (1/(1-phi^2)) (1+phi)/(1-phi). Divide by n^2: Var(xbar) is about (1/(n(1-phi^2))) (1+phi)/(1-phi), where the naive value is 1/(n(1-phi^2)). For phi = 0.5 the factor is 3; measured variance of the mean 0.00387 versus theory 0.00400 and naive 0.00133.
D5. W_t is a sum of t/dt independent increments each of variance dt, so Var = (t/dt) dt = t; the discretization uses exactly these increments, so it is exact at grid points. Measured Var(W_1) = 0.9993 (SE of that estimate about 0.0045).
D6. Var((A+B)/2) with A = f(U), B = f(1-U), equal variances v: (2v + 2 Cov)/4 = (v + Cov)/2. It beats equal-cost plain pairs (variance v/2) iff Cov < 0. For exp: (0.24204 - 0.23421)/2 = 0.003912 per pair, versus v/2 = 0.12102 for two plain draws: factor 30.9.
D7. Union bound: P(any false positive) <= sum P(test i rejects) = k (alpha/k) = alpha, without independence. (Exact under independence: 1 - (1 - alpha/k)^k = 0.0488 for k = 20, which is below 0.05.)

## Section 8.B: Reference notes

Design for `mcstats.py`: every function takes a seed or `Generator`; replications use `SeedSequence(seed).spawn(reps)`. `mean_ci(x, level, crit)` takes the critical value explicitly (the module avoids a scipy dependency; tests supply `scipy.stats.t.ppf`). Key tests with tolerances: coverage of 20,000 simulated 95% intervals within 4 x sqrt(0.95 x 0.05 / reps) = 0.0062 of 0.95 (measured 0.9495 at n = 30); Bonferroni family-wise error within 4 binomial SE of 0.0488 (SE with 5,000 reps = 0.003); `ols` equals `lstsq` to 1e-10 and `X.T @ resid` below 1e-10 (measured 6e-14); AR(1) `acf` within 4 x 1/sqrt(n) of phi^k (measured 0.497 versus 0.5 at n = 100,000); `brownian_paths` variance of W_T within 4 x T sqrt(2/(m-1)) of T; slope within 0.1 of -0.5 (measured -0.495 and -0.499 in two runs). Mutation to check: reuse one seed across replications and confirm the slope/RMSE test fails (RMSE collapses to the single-run error and does not decrease with N).

Reference implementation (run with Python 3.13.5, numpy 2.5.4, scipy 1.18.1, pytest: `python -m pytest -q`, 14 tests pass in about 2.5 s; scipy appears only in the tests). Save as `mcstats.py`:

```python
"""mcstats.py - small statistics / Monte Carlo toolkit. Python 3.12+, numpy only.

Every function takes a seed (int / SeedSequence) or a numpy Generator; there is no global RNG.
Replications get independent children via SeedSequence.spawn.
"""
from __future__ import annotations

import math
from collections.abc import Callable
from statistics import NormalDist

import numpy as np

Seed = int | np.random.SeedSequence | np.random.Generator


def make_rng(seed: Seed) -> np.random.Generator:
    """Generator from an int / SeedSequence, or the Generator itself."""
    if isinstance(seed, np.random.Generator):
        return seed
    return np.random.default_rng(seed)


def spawn_rngs(seed: int | np.random.SeedSequence, k: int) -> list[np.random.Generator]:
    """k independent generators derived from one master seed."""
    ss = seed if isinstance(seed, np.random.SeedSequence) else np.random.SeedSequence(seed)
    return [np.random.default_rng(c) for c in ss.spawn(k)]


def mean_ci(x: np.ndarray, crit: float) -> tuple[float, float, float]:
    """(mean, lo, hi) for mean +- crit * s / sqrt(n). crit is the t (or z) critical value,
    e.g. scipy.stats.t.ppf(0.975, n - 1), supplied by the caller so the module has no scipy dependency."""
    x = np.asarray(x, dtype=float)
    n = x.size
    if n < 2:
        raise ValueError("need at least 2 observations")
    m = float(x.mean())
    half = crit * float(x.std(ddof=1)) / math.sqrt(n)
    return m, m - half, m + half


def coverage_experiment(reps: int, n: int, seed: int, crit: float, mu: float = 1.0, sigma: float = 2.0) -> float:
    """Fraction of reps whose interval from n N(mu, sigma^2) draws contains mu."""
    hits = 0
    for rng in spawn_rngs(seed, reps):
        _, lo, hi = mean_ci(rng.normal(mu, sigma, n), crit)
        hits += lo <= mu <= hi
    return hits / reps


def bonferroni_experiment(k: int, reps: int, seed: int, alpha: float = 0.05) -> tuple[float, float]:
    """Family-wise error rate under k true nulls: (unadjusted at alpha, Bonferroni at alpha / k).
    Each 'test' is a two-sided z test on an N(0,1) draw, p = 2 (1 - Phi(|z|))."""
    nd = NormalDist()
    z = make_rng(seed).standard_normal((reps, k))
    p = np.array([[2 * (1 - nd.cdf(abs(v))) for v in row] for row in z])
    return float((p < alpha).any(axis=1).mean()), float((p < alpha / k).any(axis=1).mean())


def ols(X: np.ndarray, y: np.ndarray) -> tuple[np.ndarray, np.ndarray, float]:
    """Least squares by the normal equations (solve, never invert). Returns (beta, se, r2).
    X must include the intercept column if wanted. Fails loudly on rank deficiency."""
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)
    n, p = X.shape
    if n <= p:
        raise ValueError("need n > p")
    A = X.T @ X
    if np.linalg.cond(A) > 1e12:
        raise np.linalg.LinAlgError("X^T X is numerically singular")
    beta = np.linalg.solve(A, X.T @ y)
    resid = y - X @ beta
    s2 = float(resid @ resid) / (n - p)
    se = np.sqrt(s2 * np.diag(np.linalg.inv(A)))
    tss = float(((y - y.mean()) ** 2).sum())
    r2 = 1.0 - float(resid @ resid) / tss
    return beta, se, r2


def acf(x: np.ndarray, max_lag: int) -> np.ndarray:
    """Sample autocorrelation r_0..r_max_lag (r_0 = 1), divisor n (the standard biased estimator)."""
    x = np.asarray(x, dtype=float)
    if not 0 <= max_lag < x.size:
        raise ValueError("max_lag must satisfy 0 <= max_lag < len(x)")
    d = x - x.mean()
    c0 = float(d @ d)
    return np.array([float(d[: x.size - k] @ d[k:]) / c0 for k in range(max_lag + 1)])


def simulate_ar1(phi: float, n: int, seed: Seed) -> np.ndarray:
    """x_t = phi x_{t-1} + e_t, e ~ N(0,1), started from the stationary law."""
    if abs(phi) >= 1:
        raise ValueError("|phi| must be < 1 for a stationary AR(1)")
    rng = make_rng(seed)
    e = rng.standard_normal(n)
    x = np.empty(n)
    x[0] = e[0] / math.sqrt(1 - phi * phi)
    for t in range(1, n):
        x[t] = phi * x[t - 1] + e[t]
    return x


def brownian_paths(m: int, steps: int, T: float, seed: Seed) -> np.ndarray:
    """m paths on a grid of `steps` steps over [0, T]; shape (m, steps + 1), column 0 is W_0 = 0.
    Exact at grid points; the maximum over the grid underestimates the continuous maximum."""
    dt = T / steps
    inc = make_rng(seed).standard_normal((m, steps)) * math.sqrt(dt)
    return np.concatenate([np.zeros((m, 1)), np.cumsum(inc, axis=1)], axis=1)


def mc_error_vs_n(method: Callable[[int, np.random.Generator], float], true: float,
                  ns: list[int], reps: int, seed: int) -> tuple[list[float], float]:
    """RMSE of `method(n, rng)` against `true` for each n, over `reps` independent replications
    (spawned streams), and the least-squares slope of log RMSE on log n."""
    if len(ns) < 3:
        raise ValueError("need at least 3 values of n to fit a slope")
    rmses = []
    for n in ns:
        errs = np.array([method(n, rng) - true for rng in spawn_rngs(seed, reps)])
        rmses.append(math.sqrt(float(np.mean(errs ** 2))))
    slope = float(np.polyfit(np.log(ns), np.log(rmses), 1)[0])
    return rmses, slope
```

Save as `test_mcstats.py`. Tolerances come from binomial or sampling standard errors, as in the notes above. The last test is a mutation check: it shows that reusing one seed in every replication produces RMSE values that do not track the theoretical sqrt(Var/N) (it is deterministic because the seed is fixed, but it demonstrates a symptom rather than proving a property, so treat it as a smoke test).

```python
import math
import numpy as np
import pytest
from scipy import stats
import mcstats as m

def test_mean_ci_matches_scipy():
    x = np.random.default_rng(0).normal(size=25)
    crit = stats.t.ppf(0.975, 24)
    mean, lo, hi = m.mean_ci(x, crit)
    ref = stats.t.interval(0.95, 24, loc=x.mean(), scale=stats.sem(x))
    assert (lo, hi) == pytest.approx(ref, rel=1e-12)
    assert mean == pytest.approx(x.mean())

def test_mean_ci_needs_two_points():
    with pytest.raises(ValueError):
        m.mean_ci(np.array([1.0]), 2.0)

def test_coverage_within_4_se():
    reps, n = 4000, 30
    cov = m.coverage_experiment(reps, n, seed=11, crit=stats.t.ppf(0.975, n - 1))
    assert abs(cov - 0.95) < 4 * math.sqrt(0.95 * 0.05 / reps)

def test_z_interval_undercovers_small_n():
    # the t critical value matters: z at n=5 covers clearly less than 95% (about 88%)
    cov = m.coverage_experiment(4000, 5, seed=12, crit=1.959964)
    assert cov < 0.92

def test_bonferroni_family_wise_error():
    reps, k = 5000, 20
    raw, adj = m.bonferroni_experiment(k, reps, seed=3)
    th_raw, th_adj = 1 - 0.95 ** k, 1 - (1 - 0.05 / k) ** k
    assert abs(raw - th_raw) < 4 * math.sqrt(th_raw * (1 - th_raw) / reps)
    assert abs(adj - th_adj) < 4 * math.sqrt(th_adj * (1 - th_adj) / reps)
    assert adj <= 0.05 + 4 * math.sqrt(0.05 * 0.95 / reps)

def test_ols_matches_lstsq_and_residuals_orthogonal():
    rng = np.random.default_rng(5)
    X = np.column_stack([np.ones(200), rng.normal(size=(200, 3))])
    y = X @ np.array([1.0, 2.0, -1.0, 0.5]) + rng.normal(size=200)
    beta, se, r2 = m.ols(X, y)
    ref = np.linalg.lstsq(X, y, rcond=None)[0]
    assert beta == pytest.approx(ref, abs=1e-10)
    assert np.abs(X.T @ (y - X @ beta)).max() < 1e-10
    assert 0 < r2 < 1 and np.all(se > 0)

def test_ols_rejects_collinear_and_short():
    x = np.arange(10.0)
    with pytest.raises(np.linalg.LinAlgError):
        m.ols(np.column_stack([x, 2 * x]), x)
    with pytest.raises(ValueError):
        m.ols(np.ones((2, 3)), np.ones(2))

def test_acf_of_ar1():
    phi, n = 0.5, 100_000
    r = m.acf(m.simulate_ar1(phi, n, seed=1), 3)
    assert r[0] == 1.0
    for k in (1, 2, 3):
        assert abs(r[k] - phi ** k) < 4 / math.sqrt(n)

def test_acf_and_ar1_validation():
    with pytest.raises(ValueError):
        m.acf(np.arange(5.0), 5)
    with pytest.raises(ValueError):
        m.simulate_ar1(1.0, 10, seed=0)

def test_brownian_variance_and_start():
    mm, T = 20_000, 2.0
    W = m.brownian_paths(mm, 252, T, seed=4)
    assert W.shape == (mm, 253) and np.all(W[:, 0] == 0)
    assert abs(W[:, -1].var(ddof=1) - T) < 4 * T * math.sqrt(2 / (mm - 1))

def test_brownian_max_is_biased_low():
    W = m.brownian_paths(40_000, 252, 1.0, seed=3)
    mx = W.max(axis=1)
    se = mx.std(ddof=1) / math.sqrt(mx.size)
    assert mx.mean() < math.sqrt(2 / math.pi) - 5 * se

def test_error_vs_n_slope_and_plain_vs_antithetic():
    true = math.e - 1
    plain = lambda n, g: float(np.exp(g.random(n)).mean())
    anti = lambda n, g: float(((np.exp(u := g.random(n // 2)) + np.exp(1 - u)) / 2).mean())
    ns = [10 ** k for k in range(2, 6)]
    r_plain, slope = m.mc_error_vs_n(plain, true, ns, reps=300, seed=1)
    r_anti, _ = m.mc_error_vs_n(anti, true, ns, reps=300, seed=2)
    assert abs(slope + 0.5) < 0.1
    ratio = [a / b for a, b in zip(r_plain, r_anti)]
    assert all(4.0 < r < 7.5 for r in ratio)   # theory sqrt(30.9) = 5.56 at equal evaluations

def test_same_seed_reproducible_and_generators_accepted():
    assert np.array_equal(m.simulate_ar1(0.3, 50, 9), m.simulate_ar1(0.3, 50, 9))
    g = np.random.default_rng(9)
    assert m.make_rng(g) is g

def test_mutation_reused_seed_breaks_slope():
    # mutant: every replication uses the SAME stream -> RMSE equals one run's error and does not fall as 1/sqrt(n)
    true = math.e - 1
    def bad_error_vs_n(ns, reps):
        out = []
        for n in ns:
            errs = np.array([float(np.exp(np.random.default_rng(7).random(n)).mean()) - true for _ in range(reps)])
            out.append(math.sqrt(np.mean(errs ** 2)))
        return out
    ns = [10 ** k for k in range(2, 6)]
    r = bad_error_vs_n(ns, 50)
    # RMSE is the single-run error: at fixed seed it is NOT estimated from independent runs;
    # the good function gives RMSE close to theory, the mutant does not track it across all n
    th = [math.sqrt(0.24204 / n) for n in ns]
    assert max(abs(a / b - 1) for a, b in zip(r, th)) > 0.2
```

## Sections 10-12 notes

Strong answers to the design prompts: spawn gives streams with documented independence, hand-chosen seeds do not; RMSE combines bias and spread whereas mean error across replications cancels positive and negative misses; the discrete Brownian maximum misses peaks between grid points, so it underestimates; for expensive replications, use fewer replications with sample-based SE and bootstrap the SE of the RMSE instead of increasing reps blindly.

Remedial: write the 40-line simulation named in the gate for your weakest area and pin its numbers in tests with tolerances derived from the corresponding binomial or sampling SE.
