## Section 7: Retrieval answers

1. Deviations are measured from xbar, which is fitted to the same data and makes them systematically smaller; dividing by n-1 compensates exactly: E[s^2] = sigma^2. s itself is slightly biased low (square root is concave).
2. SE = 5/sqrt(25) = 1.0; z interval 4.0 +- 1.96 = (2.04, 5.96). The t critical value with 24 df is 2.0639, giving (1.94, 6.06); it widens the interval to account for estimating sigma (z undercovers: 88.1% at n = 5 in 3.1).
3. p = 0.03: if H0 and the model were true, data at least this extreme would occur 3% of the time. It is not P(H0 true), and not the effect size or the replication probability (also not "97% sure").
4. 1 - 0.95^20 = 0.642 (simulated 0.651). Bonferroni at 0.0025: 1 - 0.9975^20 = 0.0488 (simulated 0.0486).
5. S = (y - Xb)^T (y - Xb); dS/db = -2 X^T (y - Xb) = 0 gives X^T X b = X^T y.
6. Elimination on the p x p system is cheaper and more accurate than forming the inverse. QR/SVD avoid forming X^T X, which squares the condition number (measured cond(X) 2.0e7 versus cond(X^T X) 4.0e14).
7. No: in-sample R^2 cannot fall when terms are added. Out-of-sample R^2 fell from 0.469 (degree 1) to 0.069 (degree 15). Evidence is held-out or cross-validated performance.
8. Not stationary; Var(S_t) = t sigma^2 grows. Difference the series (use returns) or use cointegration methods before regressing.
9. r_1 = 0.8, r_2 = 0.64; (1-phi)/(1+phi) = 0.2/1.8 = 0.111, so n observations carry the information of about n/9.
10. SE falls 4x so N grows 16x to 160,000; compute grows 16x.
11. Antithetic pairs cost two evaluations per sample; comparing N pairs to N plain draws gives antithetics twice the compute and overstates the gain by 2x. Compare at equal evaluations.
12. f(u) = (u - 0.5)^2 (symmetric about 0.5): f(U) = f(1-U) so the covariance equals the variance and pairing wastes evaluations. Measured: antithetic variance 2.07x worse than plain at equal cost.

## Section 8.A: Derivations

D1. Write x_i - xbar = (x_i - mu) - (xbar - mu). Sum of squares = sum (x_i - mu)^2 - n (xbar - mu)^2. Expectation: n sigma^2 - n (sigma^2/n) = (n-1) sigma^2. Divide by n-1.
D2. S = sum (y_i - a - b x_i)^2. dS/da: sum(y - a - bx) = 0, so a = ybar - b xbar. dS/db: sum x(y - a - bx) = 0. Substitute a: sum x_i y_i - n xbar ybar = b (sum x_i^2 - n xbar^2), so b = Cov(x,y)/Var(x) (matching divisors).
D3. The normal equations X^T (y - Xb) = 0 say X^T r = 0, i.e. r is orthogonal to every column. Measured max |X^T r| about 6e-14 (rounding).
D4. Cov(x_s, x_t) = phi^|s-t| / (1 - phi^2). Sum over all pairs is approximately n (1/(1-phi^2)) (1 + 2 sum_{k>=1} phi^k) = n (1/(1-phi^2)) (1+phi)/(1-phi). Divide by n^2: Var(xbar) is about (1/(n(1-phi^2))) (1+phi)/(1-phi), where the naive value is 1/(n(1-phi^2)). For phi = 0.5 the factor is 3; measured variance of the mean 0.00387 versus theory 0.00400 and naive 0.00133.
D5. W_t is a sum of t/dt independent increments each of variance dt, so Var = (t/dt) dt = t; the discretization uses exactly these increments, so it is exact at grid points. Measured Var(W_1) = 0.9993 (SE of that estimate about 0.0045).
D6. Var((A+B)/2) with A = f(U), B = f(1-U), equal variances v: (2v + 2 Cov)/4 = (v + Cov)/2. It beats equal-cost plain pairs (variance v/2) iff Cov < 0. For exp: (0.24204 - 0.23421)/2 = 0.003912 per pair, versus v/2 = 0.12102 for two plain draws: factor 30.9.
D7. Union bound: P(any false positive) <= sum P(test i rejects) = k (alpha/k) = alpha, without independence. (Exact under independence: 1 - (1 - alpha/k)^k = 0.0488 for k = 20, which is below 0.05.)

Scoring: 5 points each (35); below 28 repeat missed types.

## Section 8.B: Reference notes

Design for `mcstats.py`: every function takes a seed or `Generator`; replications use `SeedSequence(seed).spawn(reps)`. `mean_ci(x, level, crit)` takes the critical value explicitly (the module avoids a scipy dependency; tests supply `scipy.stats.t.ppf`). Key tests with tolerances: coverage of 20,000 simulated 95% intervals within 4 x sqrt(0.95 x 0.05 / reps) = 0.0062 of 0.95 (measured 0.9495 at n = 30); Bonferroni family-wise error within 4 binomial SE of 0.0488 (SE with 5,000 reps = 0.003); `ols` equals `lstsq` to 1e-10 and `X.T @ resid` below 1e-10 (measured 6e-14); AR(1) `acf` within 4 x 1/sqrt(n) of phi^k (measured 0.497 versus 0.5 at n = 100,000); `brownian_paths` variance of W_T within 4 x T sqrt(2/(m-1)) of T; slope within 0.1 of -0.5 (measured -0.495 and -0.499 in two runs). Mutation to check: reuse one seed across replications and confirm the slope/RMSE test fails (RMSE collapses to the single-run error and does not decrease with N).

Alternatives: statsmodels for regression diagnostics (not used here to keep the derivation visible); `numpy.linalg.lstsq` or QR for the production solve.

Third problem: mean of the maximum of Brownian motion on [0,1] sampled at 252 steps: 0.7628 (SE 0.0019, 100,000 paths, seed 3). The continuous-time value is sqrt(2/pi) = 0.7979 (from the reflection principle; VERIFY against a probability text). The discrete maximum is biased low by about 0.035 (roughly 0.5826 sqrt(dt) = 0.0367 for the known correction constant; VERIFY the constant 0.5826 in the literature before quoting). Students must state the discretization caveat.

Coverage test: 4,000 runs of N = 1000 plain intervals covered 95.2%; antithetic intervals at 500 pairs covered 94.3% (SE of those figures about 0.35%, so both acceptable). Antithetic failure case: f(u) = (u-0.5)^2 at N = 1000: plain RMSE 0.00237, antithetic at equal cost 0.00341 (variance ratio 2.07).

## Sections 10-12 notes

Strong answers to the design prompts: spawn gives streams with documented independence, hand-chosen seeds do not; RMSE combines bias and spread whereas mean error across replications cancels positive and negative misses; the discrete Brownian maximum misses peaks between grid points, so it underestimates; for expensive replications, use fewer replications with sample-based SE and bootstrap the SE of the RMSE instead of increasing reps blindly.

Remedial: write the 40-line simulation named in the gate for your weakest area and pin its numbers in tests with tolerances derived from the corresponding binomial or sampling SE.
