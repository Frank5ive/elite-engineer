## Section 8.A: Derivation solutions

D1. R1 = 3x + y - z = 2 (swapped to the top as the largest pivot, |3|); R2 = x + 2y + z = 4; R3 = 2x - y + 2z = 7. R2 - (1/3) R1: (5/3) y + (4/3) z = 10/3. R3 - (2/3) R1: -(5/3) y + (8/3) z = 17/3. Check: 1.35 + 0.4 + 2.25 = 4; 4.05 + 0.2 - 2.25 = 2; 2.7 - 0.2 + 4.5 = 7.
D2. det(C - lambda I) = (5 - lambda)(2 - lambda) - 4 = lambda^2 - 7 lambda + 6, so lambda = 6 and 1 (trace 7, determinant 6). lambda = 6: -v1 + 2 v2 = 0, v = (2,1)/sqrt 5 = (0.8944, 0.4472). lambda = 1: 4 v1 + 2 v2 = 0, v = (-1,2)/sqrt 5. Orthogonal: 2(-1) + 1(2) = 0. Variance on the first axis: 6/7 = 85.7%.
D3. Taylor: f(x + h) = f(x) + f'(x) h + O(h^2). Drop the quadratic term and solve f(x + h) = 0: h = -f/f'. For f = x^2 - a: x - (x^2 - a)/(2x) = (x + a/x)/2. From x0 = 1, a = 2: 3/2, then 17/12, then 577/408 = 1.41421569 (error 2.1e-6 versus sqrt 2 = 1.41421356). Correct digits roughly double each step.
D4. The parabola through (-h, f_m), (0, f_0), (h, f_p) is f_0 + b x + c x^2 with c = (f_p - 2 f_0 + f_m)/(2h^2). The odd term integrates to zero over [-h, h]; integral = 2h f_0 + c (2h^3/3) = 2h f_0 + h (f_p - 2 f_0 + f_m)/3 = (h/3)(f_m + 4 f_0 + f_p). Adjacent panels share endpoints, giving weights 1, 4, 2, 4, ..., 4, 1.
D5. Expand f(x+h) and f(x-h) in Taylor series; subtracting cancels even terms: f(x+h) - f(x-h) = 2h f' + h^3 f'''/3 + ..., so the quotient is f' + h^2 f'''/6: truncation error c1 h^2, c1 = f'''/6. Rounding in the numerator is about eps |f|, so after dividing by 2h it is about c2 eps/h. Minimize c1 h^2 + c2 eps/h: 2 c1 h = c2 eps/h^2, so h = (c2 eps/(2 c1))^(1/3), proportional to eps^(1/3) = 6.06e-6. For exp at x = 1 the measured table (h = 1e-5 gives 5.9e-11) is consistent.
D6. The product of roots is c/a = 1. For b = -1e8 the large root q = (-b + sqrt(b^2 - 4ac))/(2a) adds two positive numbers (no cancellation) and equals 1e8 (measured); the small root is (c/a)/q = 1e-8 (measured).
D7. 1 - cos x = 2 sin^2(x/2), so (1 - cos x)/x^2 = (1/2)(sin(x/2)/(x/2))^2, which tends to 1/2 since sin(u)/u -> 1. At x = 1e-8 the direct form returned 0.0 and the identity returned 0.5.

// numerics.hpp - small numerics library. C++20, header-only, no dependencies.
#pragma once
#include <algorithm>
#include <cmath>
#include <cstddef>
#include <functional>
#include <limits>
#include <optional>
#include <span>
#include <stdexcept>
#include <utility>
#include <vector>

namespace num {

// ---------- floating-point comparison ----------
// True if |a-b| <= abs_tol, or |a-b| <= rel_tol * max(|a|,|b|). NaN is never equal.
inline bool almost_equal(double a, double b, double rel_tol = 1e-9, double abs_tol = 0.0) {
    if (a == b) return true;                       // handles equal infinities
    if (!std::isfinite(a) || !std::isfinite(b)) return false;
    const double d = std::fabs(a - b);
    return d <= abs_tol || d <= rel_tol * std::max(std::fabs(a), std::fabs(b));
}

// ---------- summation ----------
inline double naive_sum(std::span<const double> xs) {
    double s = 0.0;
    for (double x : xs) s += x;
    return s;
}

// Neumaier's variant of Kahan summation: also correct when a term is larger than the running sum.
// WARNING: -ffast-math / -Ofast may optimize the compensation away. Do not compile this with them.
inline double kahan_sum(std::span<const double> xs) {
    double s = 0.0, c = 0.0;
    for (double x : xs) {
        const double t = s + x;
        if (std::fabs(s) >= std::fabs(x)) c += (s - t) + x;
        else                              c += (x - t) + s;
        s = t;
    }
    return s + c;
}

// ---------- dense matrix ----------
class Matrix {
public:
    Matrix(std::size_t rows, std::size_t cols, double fill = 0.0)
        : r_(rows), c_(cols), a_(rows * cols, fill) {}
    Matrix(std::initializer_list<std::initializer_list<double>> init)
        : r_(init.size()), c_(init.size() ? init.begin()->size() : 0) {
        a_.reserve(r_ * c_);
        for (auto& row : init) {
            if (row.size() != c_) throw std::invalid_argument("ragged matrix");
            a_.insert(a_.end(), row.begin(), row.end());
        }
    }
    static Matrix identity(std::size_t n) { Matrix m(n, n); for (std::size_t i = 0; i < n; ++i) m(i, i) = 1; return m; }
    std::size_t rows() const { return r_; }
    std::size_t cols() const { return c_; }
    double& operator()(std::size_t i, std::size_t j) { return a_[i * c_ + j]; }
    double  operator()(std::size_t i, std::size_t j) const { return a_[i * c_ + j]; }

    Matrix transpose() const {
        Matrix t(c_, r_);
        for (std::size_t i = 0; i < r_; ++i) for (std::size_t j = 0; j < c_; ++j) t(j, i) = (*this)(i, j);
        return t;
    }
    friend Matrix operator*(const Matrix& A, const Matrix& B) {
        if (A.c_ != B.r_) throw std::invalid_argument("shape mismatch");
        Matrix C(A.r_, B.c_);
        for (std::size_t i = 0; i < A.r_; ++i)
            for (std::size_t k = 0; k < A.c_; ++k) {      // i-k-j order: inner loop is contiguous in B and C
                const double aik = A(i, k);
                for (std::size_t j = 0; j < B.c_; ++j) C(i, j) += aik * B(k, j);
            }
        return C;
    }
    std::vector<double> mul(std::span<const double> x) const {
        if (x.size() != c_) throw std::invalid_argument("shape mismatch");
        std::vector<double> y(r_, 0.0);
        for (std::size_t i = 0; i < r_; ++i) for (std::size_t j = 0; j < c_; ++j) y[i] += (*this)(i, j) * x[j];
        return y;
    }
    double norm_inf() const {   // max absolute row sum
        double m = 0;
        for (std::size_t i = 0; i < r_; ++i) { double s = 0; for (std::size_t j = 0; j < c_; ++j) s += std::fabs((*this)(i, j)); m = std::max(m, s); }
        return m;
    }
private:
    std::size_t r_, c_;
    std::vector<double> a_;
};

// ---------- linear solve: LU with partial pivoting ----------
// Solves A x = b. Returns nullopt if a pivot is smaller than pivot_tol * norm_inf(A) (numerically singular).
inline std::optional<std::vector<double>> solve(Matrix A, std::vector<double> b, double pivot_tol = 1e-14) {
    const std::size_t n = A.rows();
    if (A.cols() != n || b.size() != n) throw std::invalid_argument("need square system");
    const double scale = A.norm_inf();
    for (std::size_t k = 0; k < n; ++k) {
        std::size_t p = k;
        for (std::size_t i = k + 1; i < n; ++i) if (std::fabs(A(i, k)) > std::fabs(A(p, k))) p = i;
        if (std::fabs(A(p, k)) <= pivot_tol * scale) return std::nullopt;
        if (p != k) { for (std::size_t j = 0; j < n; ++j) std::swap(A(k, j), A(p, j)); std::swap(b[k], b[p]); }
        for (std::size_t i = k + 1; i < n; ++i) {
            const double f = A(i, k) / A(k, k);
            for (std::size_t j = k; j < n; ++j) A(i, j) -= f * A(k, j);
            b[i] -= f * b[k];
        }
    }
    std::vector<double> x(n);
    for (std::size_t i = n; i-- > 0;) {
        double s = b[i];
        for (std::size_t j = i + 1; j < n; ++j) s -= A(i, j) * x[j];
        x[i] = s / A(i, i);
    }
    return x;
}

// ---------- symmetric eigenproblem: cyclic Jacobi ----------
struct Eigen { std::vector<double> values; Matrix vectors; };   // vectors: column j <-> values[j]; sorted descending

inline Eigen eig_sym(Matrix A, double tol = 1e-13, int max_sweeps = 100) {
    const std::size_t n = A.rows();
    if (A.cols() != n) throw std::invalid_argument("square required");
    Matrix V = Matrix::identity(n);
    for (int sweep = 0; sweep < max_sweeps; ++sweep) {
        double off = 0, diag = 0;
        for (std::size_t i = 0; i < n; ++i) for (std::size_t j = 0; j < n; ++j) (i == j ? diag : off) += A(i, j) * A(i, j);
        if (off <= tol * tol * std::max(diag, 1e-300)) break;
        for (std::size_t p = 0; p + 1 < n; ++p)
            for (std::size_t q = p + 1; q < n; ++q) {
                if (A(p, q) == 0.0) continue;
                const double theta = (A(q, q) - A(p, p)) / (2.0 * A(p, q));
                const double t = (theta >= 0 ? 1.0 : -1.0) / (std::fabs(theta) + std::sqrt(theta * theta + 1.0));
                const double c = 1.0 / std::sqrt(t * t + 1.0), s = t * c;
                for (std::size_t k = 0; k < n; ++k) {      // A <- A J
                    const double akp = A(k, p), akq = A(k, q);
                    A(k, p) = c * akp - s * akq; A(k, q) = s * akp + c * akq;
                }
                for (std::size_t k = 0; k < n; ++k) {      // A <- J^T A
                    const double apk = A(p, k), aqk = A(q, k);
                    A(p, k) = c * apk - s * aqk; A(q, k) = s * apk + c * aqk;
                }
                for (std::size_t k = 0; k < n; ++k) {      // V <- V J
                    const double vkp = V(k, p), vkq = V(k, q);
                    V(k, p) = c * vkp - s * vkq; V(k, q) = s * vkp + c * vkq;
                }
            }
    }
    std::vector<std::size_t> idx(n);
    for (std::size_t i = 0; i < n; ++i) idx[i] = i;
    std::sort(idx.begin(), idx.end(), [&](auto a, auto b) { return A(a, a) > A(b, b); });
    Eigen out{std::vector<double>(n), Matrix(n, n)};
    for (std::size_t j = 0; j < n; ++j) {
        out.values[j] = A(idx[j], idx[j]);
        for (std::size_t i = 0; i < n; ++i) out.vectors(i, j) = V(i, idx[j]);
    }
    return out;
}

// ---------- root finding ----------
struct RootResult { double x; int iterations; bool converged; };

// Bisection: requires f(a), f(b) of opposite sign. Stops when interval width <= tol.
inline RootResult bisect(const std::function<double(double)>& f, double a, double b, double tol = 1e-12, int max_iter = 200) {
    double fa = f(a), fb = f(b);
    if (fa == 0) return {a, 0, true};
    if (fb == 0) return {b, 0, true};
    if ((fa < 0) == (fb < 0)) throw std::invalid_argument("bisect: root not bracketed");
    for (int i = 1; i <= max_iter; ++i) {
        const double m = a + (b - a) / 2;               // avoids overflow of (a+b)
        const double fm = f(m);
        if (fm == 0 || (b - a) / 2 <= tol) return {m, i, true};
        if ((fm < 0) == (fa < 0)) { a = m; fa = fm; } else { b = m; }
    }
    return {a + (b - a) / 2, max_iter, false};
}

// Newton: needs derivative. Stops when |step| <= tol*(1+|x|) or |f| == 0. Fails (converged=false) on zero derivative or non-finite iterate.
inline RootResult newton(const std::function<double(double)>& f, const std::function<double(double)>& df,
                         double x0, double tol = 1e-12, int max_iter = 50) {
    double x = x0;
    for (int i = 1; i <= max_iter; ++i) {
        const double fx = f(x), d = df(x);
        if (fx == 0) return {x, i, true};
        if (d == 0 || !std::isfinite(d)) return {x, i, false};
        const double step = fx / d;
        x -= step;
        if (!std::isfinite(x)) return {x, i, false};
        if (std::fabs(step) <= tol * (1 + std::fabs(x))) return {x, i, true};
    }
    return {x, max_iter, false};
}

// ---------- differentiation / integration ----------
inline double central_diff(const std::function<double(double)>& f, double x, double h) {
    return (f(x + h) - f(x - h)) / (2 * h);
}

inline double trapezoid(const std::function<double(double)>& f, double a, double b, std::size_t n) {
    if (n == 0) throw std::invalid_argument("n must be >= 1");
    const double h = (b - a) / static_cast<double>(n);
    double s = 0.5 * (f(a) + f(b));
    for (std::size_t i = 1; i < n; ++i) s += f(a + static_cast<double>(i) * h);
    return s * h;
}

// Composite Simpson; n must be even.
inline double simpson(const std::function<double(double)>& f, double a, double b, std::size_t n) {
    if (n == 0 || n % 2) throw std::invalid_argument("n must be even and >= 2");
    const double h = (b - a) / static_cast<double>(n);
    double s = f(a) + f(b);
    for (std::size_t i = 1; i < n; ++i) s += f(a + static_cast<double>(i) * h) * (i % 2 ? 4.0 : 2.0);
    return s * h / 3.0;
}

// Gradient descent on f with numeric gradient; returns final point. Fixed step, stops at |grad|<=tol.
inline std::vector<double> gradient_descent(const std::function<double(std::span<const double>)>& f,
                                            std::vector<double> x, double lr, int max_iter = 10000, double tol = 1e-8) {
    std::vector<double> g(x.size());
    for (int it = 0; it < max_iter; ++it) {
        double gn = 0;
        for (std::size_t i = 0; i < x.size(); ++i) {
            const double h = 1e-6 * (1 + std::fabs(x[i])), xi = x[i];
            x[i] = xi + h; const double fp = f(x);
            x[i] = xi - h; const double fm = f(x);
            x[i] = xi; g[i] = (fp - fm) / (2 * h); gn += g[i] * g[i];
        }
        if (std::sqrt(gn) <= tol) break;
        for (std::size_t i = 0; i < x.size(); ++i) x[i] -= lr * g[i];
    }
    return x;
}

} // namespace num

        }
        Matrix T{{2,-1,0},{-1,2,-1},{0,-1,2}};      // eigenvalues 2 - sqrt2, 2, 2 + sqrt2
        auto et = eig_sym(T);
        CHECK_NEAR(et.values[0], 2 + std::sqrt(2.0), 1e-12, 0); CHECK_NEAR(et.values[1], 2, 1e-12, 0); CHECK_NEAR(et.values[2], 2 - std::sqrt(2.0), 1e-12, 0);
    }
    // roots
    {
        auto f = [](double x){ return x*x - 2; }; auto df = [](double x){ return 2*x; };
        auto b = bisect(f, 1, 2, 1e-12); auto n = newton(f, df, 1.0);
        std::printf("sqrt2: bisect iters=%d x=%.17g | newton iters=%d x=%.17g\n", b.iterations, b.x, n.iterations, n.x);
        CHECK(b.converged && n.converged);
        CHECK_NEAR(b.x, std::numbers::sqrt2, 0, 1e-12); CHECK_NEAR(n.x, std::numbers::sqrt2, 1e-15, 0);
        CHECK(n.iterations < b.iterations);
        bool threw = false; try { bisect(f, 2, 3); } catch (const std::invalid_argument&) { threw = true; } CHECK(threw);
        auto bad = newton([](double x){ return x*x*x - 2*x + 2; }, [](double x){ return 3*x*x - 2; }, 0.0, 1e-12, 50);
        std::printf("newton cycle case converged=%d\n", bad.converged);
        CHECK(!bad.converged);
        auto flat = newton([](double x){ return x*x + 1; }, [](double x){ return 2*x; }, 0.0); CHECK(!flat.converged);
    }
    // integration: int_0^pi sin = 2 ; error scaling
    {
        auto s = [](double x){ return std::sin(x); };
        double prev_t = 0, prev_s = 0;
        for (std::size_t n : {8u, 16u, 32u}) {
            double et = std::fabs(trapezoid(s, 0, std::numbers::pi, n) - 2), es = std::fabs(simpson(s, 0, std::numbers::pi, n) - 2);
            std::printf("n=%zu trap err=%.3e simpson err=%.3e", n, et, es);
            if (prev_t) std::printf("  ratios %.2f %.2f", prev_t / et, prev_s / es);
            std::printf("\n"); prev_t = et; prev_s = es;
        }
        CHECK_NEAR(simpson(s, 0, std::numbers::pi, 64), 2.0, 0, 1e-7);   // measured err 6.45e-8
        CHECK_NEAR(trapezoid([](double x){ return x; }, 0, 1, 1), 0.5, 1e-15, 0);   // exact for linear
    }
    // finite differences: truncation vs rounding
    {
        auto f = [](double x){ return std::exp(x); };
        for (double h : {1e-1, 1e-3, 1e-5, 1e-8, 1e-11, 1e-14})
            std::printf("h=%.0e central-diff err=%.3e\n", h, std::fabs(central_diff(f, 1.0, h) - std::exp(1.0)));
    }
    // gradient descent on f(x,y) = (x-3)^2 + 10 (y+1)^2
    {
        auto f = [](std::span<const double> p){ return (p[0]-3)*(p[0]-3) + 10*(p[1]+1)*(p[1]+1); };
        auto x = gradient_descent(f, {0, 0}, 0.05, 10000, 1e-9);
        CHECK_NEAR(x[0], 3, 0, 1e-6); CHECK_NEAR(x[1], -1, 0, 1e-6);
        auto diverge = gradient_descent(f, {0, 0}, 0.2, 200, 1e-9);   // lr too big for the y direction (needs lr < 1/10)
        std::printf("lr=0.2 final |x|=%.3e\n", std::fabs(diverge[1]));
        CHECK(!(std::fabs(diverge[1]) < 10) );
    }
    std::printf(failures ? "%d FAILURES\n" : "ALL PASSED\n", failures);
    return failures != 0;
}

Design notes and trade-offs.

- Matrix: flat row-major `std::vector<double>`; no bounds checking in `operator()` (document it; a checked `at()` is an alternative). Multiplication uses i-k-j order. A blocked or BLAS-backed version is the production path; measure first.
- `solve` takes `A` and `b` by value (it destroys them) and returns `std::optional`. The pivot threshold is relative to `norm_inf(A)`. Alternatives: return a status with the offending pivot to help diagnose near-singularity; or build an LU object once so repeated right-hand sides are cheap.
- `eig_sym` is cyclic Jacobi with the stable rotation formula; the stopping test is off-diagonal energy relative to diagonal energy; results sorted descending. It assumes symmetry and does not check it; a debug assertion on |A_ij - A_ji| is a worthwhile addition. Jacobi is O(n^3) per sweep: fine to n of a few dozen.
- `bisect` stops on interval half-width; stopping on |f(m)| would be wrong for flat functions. `newton` returns `converged = false` rather than throwing, because non-convergence is expected on some data, whereas an unbracketed `bisect` is a caller error (exception).
- `gradient_descent` uses a central-difference gradient with h = 1e-6 (1 + |x|), a simple default; production code uses analytic gradients. A fixed learning rate is a deliberate simplification; line search or momentum are alternatives.
- `kahan_sum` is the Neumaier variant; plain Kahan fails when a term exceeds the running sum. Pairwise summation is a simpler alternative with good practical accuracy.
- A known sharp edge: `almost_equal(0, 1e-300)` is false with `abs_tol = 0`; callers comparing against zero must pass `abs_tol`.
