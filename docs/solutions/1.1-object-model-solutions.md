## Section 7: Retrieval answers

1. `is` compares identity (same object). `==` calls `__eq__` to compare values. `hash()` computes an integer used by dict/set bucket lookup; equal objects must hash equal.
2. `(1, [2, 3])`. `b` is the same tuple object as `a`; the tuple is immutable but its second element is a mutable list that was appended to.
3. `int` is immutable: `x += 1` computes a new int and rebinds `x`; other names keep the old int. `list.__iadd__` mutates in place and returns self, so every alias observes the change.
4. `list()` is called once at `def` time, exactly like `[]`: the same shared list. `n=len(DATA)` is evaluated once at definition; later changes to `DATA` are not reflected. Use `None` plus a computation in the body when the default must be fresh or current.
5. `TypeError: unhashable type`. Defining `__eq__` sets `__hash__ = None` because inheriting `object.__hash__` (identity-based) would violate "equal implies equal hash". The designers chose a loud failure over silent set/dict corruption.
6. `{1: 'c'} 1`. `1 == 1.0 == True` and they hash equally, so all three are the same key. The first key object (`1`) is retained; the value is overwritten.
7. `copy.copy` creates a new dict that shares the inner list; `deepcopy` copies the list too. `deepcopy` is wrong for objects holding resources (locks, sockets, file handles, DB sessions), for huge structures on a hot path (cost), and when sharing is intended (for example a shared registry). Immutable data usually avoids the question.
8. `f()()` returns `2` (g's `x` resolves in the enclosing scope of `f`). With `nonlocal x; x += 1; return x` inside `g` it returns `3`, and a second call of the same `g` object returns `4`. `nonlocal x` must appear inside `g` before `x` is used there, and `x` must already be bound in an enclosing function scope (not module level), else `SyntaxError`.
9. Binding the name is one reference; passing the object as the argument to `getrefcount` creates a temporary second reference. (On 3.12+, immortal objects like `None` report huge, non-meaningful counts.)
10. Traceback/log/debugger/profiler output shows `wrapper` instead of the function name and loses the docstring. Frameworks that introspect (`inspect.signature`, routing by `__name__`, dependency injection by annotations, OpenAPI generation) see the wrapper's `(*a, **k)` signature or a name collision. `__wrapped__` is missing, so `inspect.unwrap` fails.
11. Reference counting cannot free reference cycles: each member of a cycle keeps the others' counts above zero. The cyclic GC finds unreachable cycles.
12. `weakref` (for example `weakref.WeakValueDictionary`, or `weakref.ref` per entry). Cached objects must support weak references: instances of ordinary classes do, but plain `int`, `str`, `tuple`, `list` and `dict` instances do not (VERIFY on your version; subclasses of list/dict do support it). For this reason the pattern fits object-valued caches, not primitive-valued ones.

## Section 8: Challenge reference solution

```python
# challenge_once_per_key.py
import functools, time
def once_per_key(window, clock=time.monotonic):
    def decorator(fn):
        last = {}
        @functools.wraps(fn)
        def wrapper(key, *args, **kwargs):
            if not isinstance(key, str):
                raise TypeError(f"key must be str, got {type(key).__name__}")
            now = clock()
            prev = last.get(key)
            if prev is not None and now - prev < window:
                return None
            last[key] = now
            return fn(key, *args, **kwargs)
        def reset(key=None):
            last.clear() if key is None else last.pop(key, None)
        wrapper.reset = reset
        return wrapper
    return decorator
class C:
    t = 0.0
    def __call__(self): return self.t
c = C(); out = []
@once_per_key(5, clock=c)
def f(k): out.append(k); return k
@once_per_key(5, clock=c)
def g(k): return "g"
assert f("a") == "a" and f("a") is None and g("a") == "g"
c.t = 5; assert f("a") == "a"
f.reset(); assert f("a") == "a"
try: f(1)
except TypeError as e: print(e)
print("ok")
```

Trade-offs and notes:

- State lives in the closure of `decorator`, hence per decorated function. A module-level `last = {}` would make `f` and `g` interfere; the required extra test is `f("a")` then `g("a")` expecting `g` still runs.
- `last[key]` is set **before** calling `fn`: if `fn` raises, the key is still suppressed for the window. Alternative: set after success so failures can be retried immediately. Either is defensible; the spec did not say, so your answer must state the choice. This reference chooses "claim first" (prevents duplicate concurrent work) and notes it is not thread-safe either way.
- Alternative design: a class with `__call__` and an explicit `reset` method, which is easier to type-check and inspect than function attributes. Prefer it if the decorator grows beyond this.
- The wrong-key test must assert on the message type, not just that something raised, to prove `TypeError` and not `AttributeError`.

## Section 9: Project reference solution

### Design decisions

- **Key policy.** `(args, sorted kwargs items)`; unhashable raises `TypeError` before touching state. `1`, `1.0` and `True` collide because they are equal and hash equally: this is Python's own dict semantics, and `functools.lru_cache(typed=False)` behaves likewise. A `typed=True` option (include `type(a)` in the key) is a reasonable extension.
- **Expiry boundary.** Age `>= seconds` is expired. `seconds=0` therefore never hits. Documented and tested.
- **Lock placement.** Lock guards the store and counters only; `fn` runs outside the lock. Cost: concurrent misses for the same key may compute twice (benign for idempotent loads). Alternative: hold the lock during `fn` (no duplicate work, but one slow call blocks all callers, and a recursive cached call would deadlock with `threading.Lock`; `RLock` would be needed). A per-key lock or "in-flight future" table is the production-grade answer and is out of scope.
- **Copy policy.** `copy_results=True` default: safe by default, opt out for immutable results. If `deepcopy` fails the exception propagates from the call that stored or returned the value; documented.
- **None results.** The miss marker is a private `_MISSING` sentinel, so a cached `None` is a hit.
- **Exceptions.** `fn` raising skips the store step, so nothing is cached and the lock is not held (it is released by `with`).

### `objkit/cache.py`

```python
# objkit/cache.py
from __future__ import annotations

import copy
import functools
import threading
import time
from collections import OrderedDict
from collections.abc import Callable, Hashable
from typing import Any, NamedTuple, ParamSpec, TypeVar

P = ParamSpec("P")
R = TypeVar("R")
_MISSING: Any = object()


class CacheInfo(NamedTuple):
    hits: int
    misses: int
    size: int


def ttl_cache(
    seconds: float,
    *,
    maxsize: int | None = None,
    clock: Callable[[], float] = time.monotonic,
    copy_results: bool = True,
) -> Callable[[Callable[P, R]], Callable[P, R]]:
    """Cache results per (args, kwargs) for `seconds` (entry expires when age >= seconds).

    Arguments must be hashable (TypeError otherwise). Exceptions are not cached.
    With copy_results=True results are deep-copied in and out.
    Thread safety: the lock guards the store only; fn runs outside the lock, so
    concurrent misses for one key may compute twice (last writer wins).
    """
    if seconds < 0:
        raise ValueError("seconds must be >= 0")
    if maxsize is not None and maxsize < 1:
        raise ValueError("maxsize must be None or >= 1")

    def decorator(fn: Callable[P, R]) -> Callable[P, R]:
        store: OrderedDict[Hashable, tuple[float, Any]] = OrderedDict()
        lock = threading.Lock()
        stats = {"hits": 0, "misses": 0}

        @functools.wraps(fn)
        def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
            key = (args, tuple(sorted(kwargs.items())))
            hash(key)  # fail loudly before touching state
            with lock:
                hit = store.get(key, _MISSING)
                if hit is not _MISSING and clock() - hit[0] < seconds:
                    stats["hits"] += 1
                    store.move_to_end(key)
                    cached: R = copy.deepcopy(hit[1]) if copy_results else hit[1]
                    return cached
                stats["misses"] += 1
            value = fn(*args, **kwargs)
            with lock:
                store[key] = (clock(), copy.deepcopy(value) if copy_results else value)
                store.move_to_end(key)
                if maxsize is not None and len(store) > maxsize:
                    store.popitem(last=False)
            return value

        def cache_clear() -> None:
            with lock:
                store.clear()
                stats["hits"] = stats["misses"] = 0

        def cache_info() -> CacheInfo:
            with lock:
                return CacheInfo(stats["hits"], stats["misses"], len(store))

        wrapper.cache_clear = cache_clear  # type: ignore[attr-defined]
        wrapper.cache_info = cache_info  # type: ignore[attr-defined]
        return wrapper

    return decorator
```

### `objkit/views.py`

```python
# objkit/views.py
from __future__ import annotations

from collections.abc import Mapping, Sequence
from typing import Any, Iterator


def _wrap(v: Any) -> Any:
    if isinstance(v, Mapping):
        return _MapView(v)
    if isinstance(v, list):
        return _SeqView(v)
    return v


class _MapView(Mapping[Any, Any]):
    __slots__ = ("_d",)

    def __init__(self, d: Mapping[Any, Any]) -> None:
        self._d = d

    def __getitem__(self, k: Any) -> Any:
        return _wrap(self._d[k])

    def __iter__(self) -> Iterator[Any]:
        return iter(self._d)

    def __len__(self) -> int:
        return len(self._d)

    def __repr__(self) -> str:
        return f"frozen_view({self._d!r})"


class _SeqView(Sequence[Any]):
    __slots__ = ("_s",)

    def __init__(self, s: list[Any]) -> None:
        self._s = s

    def __getitem__(self, i: Any) -> Any:
        if isinstance(i, slice):
            return [_wrap(x) for x in self._s[i]]
        return _wrap(self._s[i])

    def __len__(self) -> int:
        return len(self._s)


def frozen_view(mapping: Mapping[Any, Any]) -> Mapping[Any, Any]:
    """Read-only recursive view; no copying; reflects later changes to the source."""
    return _MapView(mapping)
```

Note `frozen_view` is a lazy wrapper: no copy, later changes to the source show through, and mutation raises `TypeError` because the wrapper classes implement `Mapping`/`Sequence` (no `__setitem__`). It only recognizes `Mapping` and `list` for recursion; sets and other containers are returned as is. Say so in the docstring.

# tests/test_cache.py
import threading
import pytest
from objkit import ttl_cache, frozen_view


class Clock:
    def __init__(self): self.t = 0.0
    def __call__(self): return self.t


def test_hit_then_expiry_at_exact_boundary():
    c, calls = Clock(), []
    @ttl_cache(10, clock=c)
    def f(x): calls.append(x); return x
    f(1); f(1); assert calls == [1]
    c.t = 10  # age == seconds -> expired
    f(1); assert calls == [1, 1]


def test_functions_do_not_share_state():
    @ttl_cache(10)
    def f(x): return x
    @ttl_cache(10)
    def g(x): return -x
    assert (f(2), g(2)) == (2, -2)


def test_kwargs_order_and_values_matter():
    @ttl_cache(10)
    def f(x, **kw): return (x, kw)
    assert f(1, a=1, b=2) == f(1, b=2, a=1)
    assert f(1, a=1) != f(1, a=2)


def test_none_result_is_cached():
    calls = []
    @ttl_cache(10)
    def f(): calls.append(1); return None
    f(); f(); assert len(calls) == 1


def test_exception_not_cached():
    calls = []
    @ttl_cache(10)
    def f():
        calls.append(1)
        if len(calls) == 1: raise RuntimeError
        return "ok"
    with pytest.raises(RuntimeError): f()
    assert f() == "ok"


def test_result_mutation_does_not_corrupt_cache():
    @ttl_cache(10)
    def f(): return [1]
    f().append(2); f().append(3)
    assert f() == [1]


def test_unhashable_raises():
    @ttl_cache(10)
    def f(x): return x
    with pytest.raises(TypeError): f([1])


def test_maxsize_evicts_oldest_and_info():
    @ttl_cache(10, maxsize=2)
    def f(x): return x
    f(1); f(2); f(3)
    assert f.cache_info().size == 2
    f(1)  # was evicted -> miss
    assert f.cache_info().misses == 4


def test_metadata_and_validation():
    @ttl_cache(1)
    def f(): "doc"
    assert f.__name__ == "f" and f.__doc__ == "doc"
    with pytest.raises(ValueError): ttl_cache(-1)
    with pytest.raises(ValueError): ttl_cache(1, maxsize=0)


def test_threads_smoke():
    @ttl_cache(10)
    def f(x): return x
    ts = [threading.Thread(target=f, args=(i % 3,)) for i in range(50)]
    [t.start() for t in ts]; [t.join() for t in ts]
    assert f.cache_info().size == 3


def test_frozen_view():
    src = {"a": {"b": [1, {"c": 2}]}}
    v = frozen_view(src)
    assert v["a"]["b"][1]["c"] == 2
    with pytest.raises(TypeError): v["a"] = 1
    with pytest.raises(TypeError): v["a"]["b"][0] = 1
    src["a"]["b"][0] = 99
    assert v["a"]["b"][0] == 99

### Fixed `legacy_flags.py`

```python
# legacy_flags.py
import copy
import functools
from collections.abc import Mapping
from typing import Any

DEFAULTS: dict[str, Any] = {"beta": False, "limits": {"api": 100, "export": 10}}
_users: dict[Any, dict[str, Any]] = {}


def flags_for(user_id: Any, overrides: Mapping[str, Any] | None = None) -> dict[str, Any]:
    flags = copy.deepcopy(DEFAULTS)          # nested "limits" must not be shared
    flags.update(overrides or {})
    _users[user_id] = flags
    return flags


def raise_limit(user_id: Any, name: str, amount: int) -> dict[str, Any]:
    flags = _users.get(user_id) or flags_for(user_id)
    flags["limits"][name] += amount
    return flags


def make_checkers(names):
    return [lambda name=name: name in DEFAULTS for name in names]


class Tenant:
    def __init__(self, name):
        self.name = name
        self.members = []

    def add(self, user_id):
        self.members.append(user_id)

    def __eq__(self, other):
        if not isinstance(other, Tenant):
            return NotImplemented
        return self.name == other.name

    def __hash__(self):
        return hash(self.name)   # NOTE: name must not change while in a set


def log_calls(fn):
    @functools.wraps(fn)
    def wrapper(*a, **k):
        print("calling", fn.__name__)
        return fn(*a, **k)
    return wrapper
```

### `AUDIT.md` content (reference)

| # | Defect | Category | Cause | Fix |
|---|---|---|---|---|
| 1 | `overrides={}` | 3.3 default args | Evaluated once; shared across calls | `None` sentinel |
| 2 | `DEFAULTS.copy()` then `flags["limits"][name] += ...` | 3.4 shallow copy | Nested `limits` dict shared with `DEFAULTS` and every user; one user's raise changes everyone, and the module constant | `copy.deepcopy(DEFAULTS)` |
| 3 | `make_checkers` lambda | 3.6 late binding | Closure reads loop variable `name` at call time | `name=name` default |
| 4 | `Tenant.members = []` | 3.3/5 class attribute | One list for all instances | Create in `__init__` |
| 5 | `Tenant.__eq__` without `__hash__` and without type check | 3.9 hash/eq | Unhashable instances; `Tenant("a") == 3` raises `AttributeError` | `NotImplemented` for foreign types, hash on `name` (documented immutability assumption) |
| 6 | `log_calls` without `wraps` | 3.7 decorators | Metadata lost | `functools.wraps` |
| 7 | `_users` module-level dict unbounded | 5 / state | Grows forever; a cross-request state holder by design | Out of scope; flag in review, bound or move to a store |

### Alternative approaches worth discussing

- Use `functools.lru_cache` plus a time bucket argument (`key_time = int(clock() // seconds)`). It gives coarse, synchronised expiry with zero custom code but cannot expire an entry exactly `seconds` after its own creation.
- Return immutable results (tuples, frozen dataclasses) and drop copying entirely. This is usually the best production answer.
