## A. Retrieval practice answers (lesson section 7)

1. Prices 100 -> 120 -> 90. Simple: +20%, -25%. Log: ln(1.2) = 0.182322, ln(0.75) = -0.287682. Total simple = 90/100 - 1 = -10% (= 1.2 * 0.75 - 1). Total log = ln(0.9) = -0.105361 = 0.182322 - 0.287682. Log returns add over time; simple returns compound.
2. A portfolio's value is a weighted sum of asset values, so over one period the portfolio simple return is the weighted sum of asset simple returns (weights = start-of-period value shares). `ln` of a weighted sum is not the weighted sum of `ln`s.
3. `Var = w1^2 s1^2 + w2^2 s2^2 + 2 w1 w2 rho s1 s2 = 0.36*0.04 + 0.16*0.04 + 2*0.6*0.4*0.25*0.04 = 0.0144 + 0.0064 + 0.0048 = 0.0256`; volatility = 0.16 (16%, below the 20% weighted average).
4. Only when all pairwise correlations are +1 (for long-only weights). Any rho < 1 gives lower portfolio volatility: that gap is the diversification benefit; it is estimated and unstable (rises in stress).
5. Portfolio A: call + K e^(-rT) cash. Portfolio B: put + one share. At T if S_T > K: A = (S_T - K) + K = S_T, B = 0 + S_T. If S_T <= K: A = 0 + K, B = (K - S_T) + S_T = K. Same payoff in every state, so by no-arbitrage same price now: C + K e^(-rT) = P + S_0. Uses: European exercise, no dividends, constant r, frictionless trading, no arbitrage. Does not use Black-Scholes or any distribution of S.
6. The hedge portfolio (long option, short `V_S` shares) has no `dW` term, so it is riskless and must earn r. mu appears only multiplied by the terms that cancel (`mu S V_S` from the option and `-V_S mu S` from the shares). So the price does not depend on the expected return, only on sigma and r.
7. Any five of: (a) constant volatility - implied vol varies with strike and maturity (smile/skew); (b) lognormal returns - real returns have fat tails and jumps; (c) continuous, costless hedging - trading is discrete with spreads and impact; (d) constant risk-free rate - rates move; (e) no dividends - most equities pay them; (f) unlimited borrowing/shorting at r - funding spreads and borrow costs exist; (g) European exercise.
8. Difference = 10.46 - 10.4506 = 0.0094 = 0.31 SE. No evidence of a bug; it is ordinary sampling noise. Suspect a bug when the gap is many SE (say > 4) and persists across reseeds, or does not shrink as n grows (suggests bias: wrong drift, discounting, or payoff).
9. SE scales like 1/sqrt(n): quadrupling n halves it (factor 0.5).
10. P&L `[-4,-2,0,1,1,2,3,3,5,8]` gives losses `[4,2,0,-1,-1,-2,-3,-3,-5,-8]`. At 80% the tail holds (1 - 0.8) x 10 = 2 scenarios, so k = 2: the worst two losses are 4 and 2. VaR80 is the k-th worst loss, 2; ES80 is the mean of the k worst losses, (4 + 2) / 2 = 3. (In code, compute k as `ceil(round((1 - alpha) * n, 9))` or subtract a small epsilon before `ceil`: floating point gives `(1 - 0.7) * 10 = 3.0000000000000004`, whose `ceil` is 4 instead of 3.) Code output: `(2, 3.0)`.
11. VaR ignores the size of losses beyond the threshold (two portfolios with the same VaR can have very different tails); it is not subadditive in general, so it can penalise diversification; it is sensitive to window and sample (1000 points at 99% means 10 tail points). ES averages the tail, is subadditive, so it fixes the first two; it does not fix model/sample dependence, it needs even more tail data, and it is harder to backtest.
12. The step 1e-12 is far too small for double precision. Near S = 100 adjacent doubles are 1.4e-14 apart, so `S + 1e-12` is rounded to a grid and the actual bump is not 1e-12 (measured: `(100.0 + 1e-12) - 100.0 = 9.95e-13`, about 0.5% off). The numerator `price(S+h) - price(S)` is about delta x 1e-12, roughly 6e-13, but each price near 10 has a resolution of only 1.8e-15, so the subtraction cancels almost all significant digits. Measured for a Black-Scholes call (S = K = 100, r = 0.05, sigma = 0.2, T = 1): the exact delta is 0.636831; the h = 1e-12 estimate is 0.632383 (0.7% error), and h = 1e-8 gives 0.636830. Truncation error of the one-sided difference is O(h) and is not the problem; round-off is. Use a central difference with a relative bump around 1e-4 to 1e-6 and validate by sweeping h (the exact digits depend on the function; the principle is the sweep).

## C. Independent implementation challenge: implied volatility

Reference implementation (`quantlib/iv.py`):

```python
from __future__ import annotations
import math
from dataclasses import replace
from quantlib.bs import Option, bs_price


def implied_vol(price: float, o: Option, vol_tol: float = 1e-12, max_iter: int = 200) -> float:
    """Bisection on sigma. `o.vol` is ignored. Price is strictly increasing in sigma
    (vega > 0), so a sign change on [lo, hi] brackets exactly one root."""
    disc = math.exp(-o.rate * o.t)
    if o.kind == "call":
        lower, upper = max(o.spot - o.strike * disc, 0.0), o.spot
    else:
        lower, upper = max(o.strike * disc - o.spot, 0.0), o.strike * disc
    if not (lower <= price < upper):
        raise ValueError(f"price {price} outside no-arbitrage bounds [{lower}, {upper})")
    lo, hi = 1e-6, 5.0
    if bs_price(replace(o, vol=hi)) < price or bs_price(replace(o, vol=lo)) > price:
        raise ValueError("price not attainable with sigma in [1e-6, 5]")
    for _ in range(max_iter):
        mid = 0.5 * (lo + hi)
        if bs_price(replace(o, vol=mid)) > price: hi = mid
        else: lo = mid
        # stop on the width of the sigma interval, NOT on |price error|: where vega is tiny
        # (deep ITM, short-dated) a price error of 1e-10 still leaves sigma uncertain by ~1e-5
        if hi - lo < vol_tol:
            return 0.5 * (lo + hi)
    raise RuntimeError("bisection did not converge")
```

Trade-offs and notes:

- Why bisection is safe: for fixed other inputs the Black-Scholes price is strictly increasing in sigma (vega = S phi(d1) sqrt(T) > 0), so there is a unique root and a sign change brackets it. It converges linearly (about 1 bit per iteration; 40 iterations from width 5 reach 5e-12).
- Newton with vega: quadratic convergence but fails when vega is tiny (deep ITM/OTM, short dated: step = error / vega explodes), can overshoot out of [0, inf), and needs a safeguard (bracket + fall back to bisection). A hybrid (Newton inside a maintained bracket) is the production choice.
- Alternative stopping criteria: stopping on price error is the natural first attempt and is wrong here. Found while writing this solution: with a price tolerance of 1e-10, the call with S=100, K=80, r=5%, sigma=5%, T=1 (price 23.9016, vega = 1.15e-5) returned sigma = 0.0499926, off by 7.4e-6, because a 1e-10 price error corresponds to 1e-10 / 1.15e-5 = 9e-6 in sigma. The test with `places=6` caught it. Stopping on sigma-interval width fixed it. Lesson: the tolerance must be set on the quantity you promise the caller.
- Prices below the attainable range (price corresponding to sigma < 1e-6) raise `ValueError` by design; the round trip test accepts that only for such cases (none happened in the grid: 0 skipped).

## D. Project reference solution

`quantlib/bs.py`:

```python
"""Black-Scholes pricer, Monte Carlo, Greeks, risk. Python 3.12+, stdlib only."""
from __future__ import annotations
import math
import random
from dataclasses import dataclass
from statistics import NormalDist

_N = NormalDist()


@dataclass(frozen=True)
class Option:
    spot: float
    strike: float
    rate: float   # continuously compounded, annual
    vol: float    # annualised, > 0
    t: float      # years, > 0
    kind: str     # "call" or "put"

    def __post_init__(self) -> None:
        if self.kind not in ("call", "put"):
            raise ValueError("kind must be 'call' or 'put'")
        if self.spot <= 0 or self.strike <= 0 or self.vol <= 0 or self.t <= 0:
            raise ValueError("spot, strike, vol, t must be > 0")


def _d1_d2(o: Option) -> tuple[float, float]:
    sq = o.vol * math.sqrt(o.t)
    d1 = (math.log(o.spot / o.strike) + (o.rate + 0.5 * o.vol**2) * o.t) / sq
    return d1, d1 - sq


def bs_price(o: Option) -> float:
    d1, d2 = _d1_d2(o)
    disc = math.exp(-o.rate * o.t)
    if o.kind == "call":
        return o.spot * _N.cdf(d1) - o.strike * disc * _N.cdf(d2)
    return o.strike * disc * _N.cdf(-d2) - o.spot * _N.cdf(-d1)


def mc_price(o: Option, n_paths: int, seed: int) -> tuple[float, float]:
    """Return (estimate, standard_error). Antithetic variates, one step to T."""
    rng = random.Random(seed)
    drift = (o.rate - 0.5 * o.vol**2) * o.t
    diff = o.vol * math.sqrt(o.t)
    disc = math.exp(-o.rate * o.t)
    sign = 1.0 if o.kind == "call" else -1.0
    vals = []
    for _ in range(n_paths // 2):
        z = rng.gauss(0.0, 1.0)
        pair = 0.0
        for zz in (z, -z):
            st = o.spot * math.exp(drift + diff * zz)
            pair += max(sign * (st - o.strike), 0.0)
        vals.append(disc * pair / 2.0)
    m = sum(vals) / len(vals)
    var = sum((v - m) ** 2 for v in vals) / (len(vals) - 1)
    return m, math.sqrt(var / len(vals))


def greeks_fd(o: Option, h_rel: float = 1e-4) -> dict[str, float]:
    """Central finite differences on bs_price. Bump sizes documented in lesson."""
    from dataclasses import replace
    hs = o.spot * h_rel
    up, dn = bs_price(replace(o, spot=o.spot + hs)), bs_price(replace(o, spot=o.spot - hs))
    p0 = bs_price(o)
    delta = (up - dn) / (2 * hs)
    gamma = (up - 2 * p0 + dn) / hs**2
    hv = 1e-4
    vega = (bs_price(replace(o, vol=o.vol + hv)) - bs_price(replace(o, vol=o.vol - hv))) / (2 * hv)
    ht = 1e-5 if o.t > 2e-5 else o.t / 4
    theta = -(bs_price(replace(o, t=o.t + ht)) - bs_price(replace(o, t=o.t - ht))) / (2 * ht)
    hr = 1e-5
    rho = (bs_price(replace(o, rate=o.rate + hr)) - bs_price(replace(o, rate=o.rate - hr))) / (2 * hr)
    return {"delta": delta, "gamma": gamma, "vega": vega, "theta": theta, "rho": rho}


def greeks_analytic(o: Option) -> dict[str, float]:
    d1, d2 = _d1_d2(o)
    pdf = _N.pdf(d1)
    disc = math.exp(-o.rate * o.t)
    sq = math.sqrt(o.t)
    gamma = pdf / (o.spot * o.vol * sq)
    vega = o.spot * pdf * sq
    if o.kind == "call":
        delta = _N.cdf(d1)
        theta = -o.spot * pdf * o.vol / (2 * sq) - o.rate * o.strike * disc * _N.cdf(d2)
        rho = o.strike * o.t * disc * _N.cdf(d2)
    else:
        delta = _N.cdf(d1) - 1
        theta = -o.spot * pdf * o.vol / (2 * sq) + o.rate * o.strike * disc * _N.cdf(-d2)
        rho = -o.strike * o.t * disc * _N.cdf(-d2)
    return {"delta": delta, "gamma": gamma, "vega": vega, "theta": theta, "rho": rho}


# ---- risk ----
def historical_var_es(pnl: list[float], alpha: float = 0.99) -> tuple[float, float]:
    """VaR and ES as positive loss numbers. Empirical: k = ceil((1-alpha)*n) worst
    outcomes; VaR = k-th worst loss; ES = mean of the k worst losses."""
    if not pnl:
        raise ValueError("empty pnl")
    if not 0 < alpha < 1:
        raise ValueError("alpha in (0,1)")
    losses = sorted((-x for x in pnl), reverse=True)
    # tolerance guards against float noise: (1-0.99)*1000 == 10.000000000000009
    k = max(1, math.ceil((1 - alpha) * len(losses) - 1e-9))
    tail = losses[:k]
    return tail[-1], sum(tail) / k


def parametric_var_es(mu: float, sigma: float, alpha: float = 0.99) -> tuple[float, float]:
    """Normal model of P&L ~ N(mu, sigma^2). Positive loss numbers."""
    z = _N.inv_cdf(alpha)
    var = -mu + sigma * z
    es = -mu + sigma * _N.pdf(z) / (1 - alpha)
    return var, es


def portfolio_variance(w: list[float], cov: list[list[float]]) -> float:
    n = len(w)
    return sum(w[i] * cov[i][j] * w[j] for i in range(n) for j in range(n))
```

## E. Engineering review prompts: model answers (short)

- Antithetic SE: pair averages `(f(Z)+f(-Z))/2` are i.i.d., so the sample variance of those n/2 values divided by n/2 estimates the variance of the mean. Using all n payoffs as if independent ignores the negative correlation and overstates the SE (conservative but wrong), or in other estimators understates it.
- Bumps: relative 1e-4 for spot (from the sweep), 1e-4 absolute for vol, 1e-5 for time and rate; first-derivative error is about h^2 f'''/6.
- Historical vs parametric difference on a sample: sampling noise in the tail (k = 10 points at n = 1000) plus any non-normality of the generating process.
- Path-dependent payoff: need time-stepping (no single-step shortcut), monitoring frequency enters the price, Greeks by bumping need common random numbers.
