## A. Retrieval practice answers

1. `f(n) = O(g(n))` iff there exist `c > 0, n0` such that `f(n) <= c*g(n)` for all `n >= n0`. Example: finding a key among 16 ints by linear scan of a contiguous array (O(n)) beats a pointer-based balanced tree (O(log n)): the scan touches one or two cache lines with predictable access, the tree takes several dependent pointer loads, each a possible cache miss. Say "typically"; confirm by measuring.
2. Doubling: copies at sizes 1, 2, 4, ..., 2^k < n sum to less than 2n; adding n element writes, total work < 3n, so < 3 per push amortized. Factor 1.5: copies sum to `n * (1/1.5 + 1/1.5^2 + ...) = 2n` copies at most, so still O(1) amortized with a different constant (and less memory slack, more reallocations). Fixed increment 100: roughly `n/100` growths, each copying up to n elements, total about `n^2/200`: O(n) amortized, i.e. quadratic overall. Geometric growth is what matters.
3. If the new element is constructed after the old buffer is destroyed or moved-from, a reference `x = v[0]` passed to `push_back` points at a dead or moved-from object: use-after-free or reading a moved-from value. Constructing first reads `x` while the old buffer is still alive. The lesson test `s.push_back(s[0])` over 100 pushes exercises this; observed with g++ 14.2 `-fsanitize=address`: moving the `construct_at` after `adopt` makes ASan report `heap-use-after-free` (READ of size 8 in the `std::string` copy constructor called from `emplace_back`, freed by `Vec::deallocate` via `adopt`).
4. For a type whose move constructor can throw (not `noexcept`) and that is copy-constructible, it returns `const T&` (so the element is copied); otherwise `T&&`. Copying leaves the source intact, so if element k throws, the old buffer is still fully valid and `Vec` can destroy the partial new buffer and rethrow: strong guarantee. Moving then failing would leave the old buffer half moved-from. (cppreference: `std::move_if_noexcept`.)
5. I1: capacity is a power of two (the mask works). I2: `used_*4 <= capacity*3` after every insert, so an `Empty` slot exists. I3: every Full key is reachable from its home slot by +1 steps without crossing an `Empty`. I2 makes `find` terminate; I3 makes it correct.
6. Writing `Empty` into the middle of a probe chain makes later keys of that chain unreachable (I3 violated). Tombstones cost: they lengthen probe sequences and occupy slots; the code counts them in `used_` (so I2 holds) and `rehash` drops them, at the same capacity if live data is sparse (`(size_+1)*2 <= capacity`), doubling otherwise.
7. Invariant: all `a[j]` with `j < lo` satisfy `a[j] < x`; all `a[j]` with `j >= hi` satisfy `!(a[j] < x)`. With `hi = mid - 1` on `size_t`: `a[mid]` may be the answer and is excluded, and when `mid == 0` the subtraction wraps to `SIZE_MAX` (a loop that reads out of bounds).
8. `v.push_back(4)` with size 3 == capacity 3 reallocates, so `it` dangles and `*it` is undefined behaviour (language rule: reallocation invalidates all iterators; cppreference, `std::vector::push_back`). In practice libstdc++ reads freed memory; run under ASan and it reports `heap-use-after-free` (observed with g++ 14.2). Without sanitizers it may print 1 or garbage. Note that capacity after `vector{1,2,3}` is implementation-defined in principle (typically 3); the invalidation rule only applies if reallocation happens, which is what makes the code a bug: it relies on capacity.
9. Negative edge weights. The proof: when `u` is popped with the smallest tentative distance, any other path to `u` goes through an unfinalized vertex and so costs at least as much, because adding edges never decreases cost; with a negative edge that "at least as much" step is false. Counterexample: s->a (2), s->b (3), b->a (-2): Dijkstra finalizes a with 2 but the best is 1. Use Bellman-Ford (O(VE), detects negative cycles) or, for DAGs, topological relaxation.
10. `<=` is not a strict weak ordering (irreflexivity fails: `comp(a, a)` is true). The standard says the behaviour is undefined. Observed with g++ 14.2: sorting 1000 equal ints with this comparator under ASan fails with `heap-buffer-overflow` inside `__unguarded_partition` (the partition loop relies on the comparator being false for equal elements to stop at a sentinel); at `-O2` without ASan the same program returned normally, which is why UB is dangerous: it can look fine. Fix: `a < b`.
11. `T(n) = 2T(n/2) + cn`; each of the `log2 n` levels does cn work; `T(n) = O(n log n)` (master theorem case 2). Space: O(n) for the temporary buffer, plus O(log n) recursion depth. Stability: elements from the right run move before an equal left element only if `less(right, left)` is strictly true; for equal keys the left element is taken first, preserving original order.
12. Table answers (sample, accept any justified choice): append/iterate: `vector`, falsify with a `deque` run showing equal or better time with cache-resident data; middle insert: `vector`, falsify by finding the n above which `list` wins on your machine (if any); lookup without order: `unordered_map`, falsify with a flat table on your key distribution and table size; ordered/range: `map` or sorted vector depending on mutation rate, falsify by mixing build and lookup ratios; top-K: `priority_queue` for streams, `nth_element` for batches, falsify by sweeping k/n; ring buffer for fixed FIFO, falsify with tail latency and allocation counts.

## C. Challenge 1: `RingQueue<T>`

Approach: a circular buffer with head index and size; element `i` lives at `(head + i) % cap`. Growth copies elements in logical order to the start of a larger buffer and resets `head` to 0, which is exactly where the "growth while wrapped" bug lives (a naive `memcpy` of the raw array loses order). `push` takes its argument by value so it cannot alias storage that `grow()` relocates. `pop` moves out the front *before* destroying it so a throwing move leaves the queue unchanged.

A bug I made writing the reference: `grow()` called `destroy_all()`, which also resets `size_` to 0, and the differential test failed on its first size check. The fix is in the code. This is the value of the oracle test; keep it.

```cpp
// file: ring_queue.hpp  (C++20)
#pragma once
#include <cstddef>
#include <memory>
#include <utility>

// Invariant: cap_ == 0 (buf_ == nullptr) or head_ < cap_; size_ <= cap_;
//            live elements are buf_[(head_ + i) % cap_] for i in [0, size_); all other slots are raw.
template <class T>
class RingQueue {
    T* buf_ = nullptr;
    std::size_t cap_ = 0, head_ = 0, size_ = 0;

    T& slot(std::size_t i) noexcept { return buf_[(head_ + i) % cap_]; }
    const T& slot(std::size_t i) const noexcept { return buf_[(head_ + i) % cap_]; }

    void grow() {
        const std::size_t ncap = cap_ ? cap_ * 2 : 4;
        T* nb = std::allocator<T>{}.allocate(ncap);
        std::size_t i = 0;
        try {
            for (; i < size_; ++i) std::construct_at(nb + i, std::move_if_noexcept(slot(i)));  // unwraps the ring
        } catch (...) {
            std::destroy(nb, nb + i);
            std::allocator<T>{}.deallocate(nb, ncap);
            throw;
        }
        const std::size_t n = size_;
        destroy_all();  // resets members; size_ restored below
        buf_ = nb;
        cap_ = ncap;
        head_ = 0;
        size_ = n;
    }
    void destroy_all() noexcept {
        for (std::size_t i = 0; i < size_; ++i) std::destroy_at(&slot(i));
        if (buf_) std::allocator<T>{}.deallocate(buf_, cap_);
        buf_ = nullptr; cap_ = 0; head_ = 0; size_ = 0;
    }

public:
    RingQueue() noexcept = default;
    RingQueue(const RingQueue& o) : RingQueue() { for (std::size_t i = 0; i < o.size_; ++i) push(o.slot(i)); }
    RingQueue(RingQueue&& o) noexcept
        : buf_(std::exchange(o.buf_, nullptr)), cap_(std::exchange(o.cap_, 0)),
          head_(std::exchange(o.head_, 0)), size_(std::exchange(o.size_, 0)) {}
    RingQueue& operator=(RingQueue o) noexcept {
        std::swap(buf_, o.buf_); std::swap(cap_, o.cap_); std::swap(head_, o.head_); std::swap(size_, o.size_);
        return *this;
    }
    ~RingQueue() { destroy_all(); }

    std::size_t size() const noexcept { return size_; }
    bool empty() const noexcept { return size_ == 0; }
    T& front() noexcept { return buf_[head_]; }  // precondition: !empty()

    void push(T x) {  // by value: x cannot alias storage that grow() relocates
        if (size_ == cap_) grow();
        std::construct_at(&buf_[(head_ + size_) % cap_], std::move(x));
        ++size_;
    }
    T pop() {  // precondition: !empty(); if the move throws, the queue is unchanged
        T v = std::move(buf_[head_]);
        std::destroy_at(&buf_[head_]);
        head_ = (head_ + 1) % cap_;
        --size_;
        return v;
    }
};
```

Alternatives: (a) capacity fixed at construction, `push` returns `bool` (the usual choice between threads or stages; lesson 5.6); (b) power-of-two capacity and mask instead of `%` (faster, a measured micro-optimization, not a first version); (c) `std::deque` or `std::queue<T>`, which is the right production answer unless you need bounded memory and no allocation after startup.

## D. Challenge 2: `LruCache<K,V>`

Approach: the list holds entries in recency order; the map points at list nodes. `std::list::splice` moves a node to the front in O(1) without invalidating iterators or references, which is why `list` (normally a poor default) is appropriate here. The `put` insert path is exception-safe with respect to keeping both structures in sync. Trade-off: two allocations per entry (list node, map node) and poor locality; a production cache would consider intrusive lists or a flat hash plus index-linked list, after measuring. Returning `V*` from `get` is valid only until the next `put`/`get` that may evict that entry; document it.

```cpp
// file: lru.hpp  (C++20)
#pragma once
#include <cstddef>
#include <list>
#include <stdexcept>
#include <unordered_map>
#include <utility>

// Invariant: idx_ and items_ contain exactly the same keys; idx_[k] points at k's node in items_;
//            items_ is ordered most recent -> least recent; items_.size() <= cap_ between operations.
template <class K, class V>
class LruCache {
    using List = std::list<std::pair<K, V>>;
    std::size_t cap_;
    List items_;
    std::unordered_map<K, typename List::iterator> idx_;

public:
    explicit LruCache(std::size_t cap) : cap_(cap) {
        if (cap == 0) throw std::invalid_argument("LruCache: capacity must be > 0");
    }
    std::size_t size() const noexcept { return items_.size(); }

    V* get(const K& k) {
        auto it = idx_.find(k);
        if (it == idx_.end()) return nullptr;
        items_.splice(items_.begin(), items_, it->second);  // O(1), iterators stay valid
        return &it->second->second;
    }
    void put(K k, V v) {
        if (auto it = idx_.find(k); it != idx_.end()) {
            it->second->second = std::move(v);
            items_.splice(items_.begin(), items_, it->second);
            return;
        }
        items_.emplace_front(std::move(k), std::move(v));
        try { idx_.emplace(items_.front().first, items_.begin()); }
        catch (...) { items_.pop_front(); throw; }  // keep map and list in sync
        if (items_.size() > cap_) {
            idx_.erase(items_.back().first);
            items_.pop_back();
        }
    }
};
```

Alternative: store `std::list<K>` and `unordered_map<K, pair<V, iterator>>`, which avoids duplicating the key in two nodes but makes the code less direct.

```cpp
// file: algos.hpp  (C++20)
#pragma once
#include <algorithm>
#include <functional>
#include <string>
#include <utility>
#include <vector>

// Stable top-down merge sort. Requires T default-constructible and movable. O(n log n) time, O(n) space.
template <class T, class Less = std::less<>>
void merge_sort(std::vector<T>& v, Less less = {}) {
    std::vector<T> tmp(v.size());
    auto rec = [&](auto&& self, std::size_t lo, std::size_t hi) -> void {
        if (hi - lo < 2) return;
        const std::size_t mid = lo + (hi - lo) / 2;
        self(self, lo, mid);
        self(self, mid, hi);
        std::size_t i = lo, j = mid, k = lo;
        while (i < mid && j < hi) tmp[k++] = less(v[j], v[i]) ? std::move(v[j++]) : std::move(v[i++]);  // right wins only if strictly less: stability
        while (i < mid) tmp[k++] = std::move(v[i++]);
        while (j < hi) tmp[k++] = std::move(v[j++]);
        for (k = lo; k < hi; ++k) v[k] = std::move(tmp[k]);
    };
    rec(rec, 0, v.size());
}

// Edit distance (insert, delete, substitute, cost 1 each). dp[i][j] = distance(a[0..i), b[0..j)).
// Recurrence: min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1] + (a[i-1] != b[j-1])). Two rows suffice.
inline std::size_t edit_distance(const std::string& a, const std::string& b) {
    std::vector<std::size_t> prev(b.size() + 1), cur(b.size() + 1);
    for (std::size_t j = 0; j <= b.size(); ++j) prev[j] = j;  // a empty: j insertions
    for (std::size_t i = 1; i <= a.size(); ++i) {
        cur[0] = i;                                           // b empty: i deletions
        for (std::size_t j = 1; j <= b.size(); ++j)
            cur[j] = std::min({prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (a[i - 1] != b[j - 1] ? 1u : 0u)});
        std::swap(prev, cur);
    }
    return prev[b.size()];
}

struct Interval { int start, end; };  // half-open [start, end)

// Greedy: sort by end, take each interval that starts at or after the last taken end.
// Exchange argument: an optimal solution can always be rewritten to contain the earliest-finishing interval.
inline std::size_t max_non_overlapping(std::vector<Interval> v) {
    std::sort(v.begin(), v.end(), [](const Interval& a, const Interval& b) { return a.end < b.end; });
    std::size_t count = 0;
    bool have = false;
    int last_end = 0;
    for (const Interval& iv : v)
        if (!have || iv.start >= last_end) { ++count; last_end = iv.end; have = true; }
    return count;
}
```

```cpp
// file: graph.hpp  (C++20)
#pragma once
#include <functional>
#include <limits>
#include <memory>
#include <queue>
#include <stack>
#include <stdexcept>
#include <vector>

struct Edge { int to; long long w; };
using Graph = std::vector<std::vector<Edge>>;
inline constexpr long long kInf = std::numeric_limits<long long>::max();

// Fewest-edge distance; -1 if unreachable. Invariant: queue holds vertices in non-decreasing distance order.
inline std::vector<int> bfs_dist(const Graph& g, int s) {
    std::vector<int> d(g.size(), -1);
    std::queue<int> q;
    d[static_cast<std::size_t>(s)] = 0;
    q.push(s);
    while (!q.empty()) {
        const int u = q.front(); q.pop();
        for (const Edge& e : g[static_cast<std::size_t>(u)])
            if (d[static_cast<std::size_t>(e.to)] < 0) {
                d[static_cast<std::size_t>(e.to)] = d[static_cast<std::size_t>(u)] + 1;
                q.push(e.to);
            }
    }
    return d;
}

inline void dfs_rec(const Graph& g, int u, std::vector<char>& seen, std::vector<int>& order) {
    seen[static_cast<std::size_t>(u)] = 1;
    order.push_back(u);
    for (const Edge& e : g[static_cast<std::size_t>(u)])
        if (!seen[static_cast<std::size_t>(e.to)]) dfs_rec(g, e.to, seen, order);  // depth up to V: stack risk
}
// Same preorder as dfs_rec, with an explicit stack (heap memory instead of call stack).
inline std::vector<int> dfs_iter(const Graph& g, int s) {
    std::vector<char> seen(g.size(), 0);
    std::vector<int> order;
    std::stack<int> st;
    st.push(s);
    while (!st.empty()) {
        const int u = st.top(); st.pop();
        if (seen[static_cast<std::size_t>(u)]) continue;
        seen[static_cast<std::size_t>(u)] = 1;
        order.push_back(u);
        const auto& adj = g[static_cast<std::size_t>(u)];
        for (auto it = adj.rbegin(); it != adj.rend(); ++it)  // reversed so the first neighbour is popped first
            if (!seen[static_cast<std::size_t>(it->to)]) st.push(it->to);
    }
    return order;
}
inline std::vector<int> dfs_recursive(const Graph& g, int s) {
    std::vector<char> seen(g.size(), 0);
    std::vector<int> order;
    dfs_rec(g, s, seen, order);
    return order;
}

// Dijkstra, binary heap with lazy deletion. Requires all weights >= 0 (checked) and no overflow of path sums.
// Invariant: when (du, u) is popped with du == d[u], d[u] is final.
inline std::vector<long long> dijkstra(const Graph& g, int s) {
    for (const auto& adj : g)
        for (const Edge& e : adj)
            if (e.w < 0) throw std::invalid_argument("dijkstra: negative edge weight");
    std::vector<long long> d(g.size(), kInf);
    using QE = std::pair<long long, int>;
    std::priority_queue<QE, std::vector<QE>, std::greater<>> pq;
    d[static_cast<std::size_t>(s)] = 0;
    pq.emplace(0, s);
    while (!pq.empty()) {
        const auto [du, u] = pq.top();
        pq.pop();
        if (du > d[static_cast<std::size_t>(u)]) continue;  // stale entry
        for (const Edge& e : g[static_cast<std::size_t>(u)]) {
            const long long nd = du + e.w;
            if (nd < d[static_cast<std::size_t>(e.to)]) {
                d[static_cast<std::size_t>(e.to)] = nd;
                pq.emplace(nd, e.to);
            }
        }
    }
    return d;
}
```

```cpp
        for (unsigned mask = 0; mask < (1u << v.size()); ++mask) {
            std::vector<Interval> pick;
            for (std::size_t i = 0; i < v.size(); ++i) if (mask >> i & 1u) pick.push_back(v[i]);
            std::sort(pick.begin(), pick.end(), [](auto& a, auto& b) { return a.start < b.start; });
            bool ok = true;
            for (std::size_t i = 1; i < pick.size(); ++i) if (pick[i].start < pick[i - 1].end) ok = false;
            if (ok) best = std::max(best, pick.size());
        }
        CHECK(max_non_overlapping(v) == best);
    }
}
```

## F. Project reference notes

`FlatMap` and `BinaryHeap` are in the lesson. Reference `ChainMap` (separate chaining, load factor <= 1.0). Two things to check in your own version: rehash relinks every node exactly once with no node allocation, and the destructor is iterative (the test with a degenerate hash of 20,000 colliding keys exists for this).

```cpp
// file: chain_map.hpp  (C++20)
#pragma once
#include <cstddef>
#include <cstdint>
#include <functional>
#include <memory>
#include <utility>
#include <vector>

// Invariant: every node n lives in bucket mix(hash(n.key)) & (buckets-1); keys are unique; size_ == node count;
//            size_ <= buckets (load factor <= 1.0) after every insert.
template <class K, class V, class Hash = std::hash<K>>
class ChainMap {
    struct Node { K key; V val; std::unique_ptr<Node> next; };
    std::vector<std::unique_ptr<Node>> b_ = std::vector<std::unique_ptr<Node>>(8);
    std::size_t size_ = 0;
    [[no_unique_address]] Hash hash_{};

    static std::size_t mix(std::uint64_t x) noexcept {
        x += 0x9e3779b97f4a7c15ull;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ull;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebull;
        return static_cast<std::size_t>(x ^ (x >> 31));
    }
    std::size_t idx(const K& k, std::size_t nb) const noexcept { return mix(hash_(k)) & (nb - 1); }
    void rehash(std::size_t nb) {  // relinks each node exactly once; no allocation of nodes
        std::vector<std::unique_ptr<Node>> nv(nb);
        for (auto& head : b_) {
            while (head) {
                std::unique_ptr<Node> n = std::move(head);
                head = std::move(n->next);
                const std::size_t i = idx(n->key, nb);
                n->next = std::move(nv[i]);
                nv[i] = std::move(n);
            }
        }
        b_ = std::move(nv);
    }

public:
    ChainMap() = default;
    ChainMap(const ChainMap&) = delete;
    ChainMap& operator=(const ChainMap&) = delete;
    ~ChainMap() {  // iterative: a long chain (bad hash) must not recurse through unique_ptr destructors
        for (auto& head : b_) while (head) head = std::move(head->next);
    }
    std::size_t size() const noexcept { return size_; }

    bool insert_or_assign(K k, V v) {
        if (size_ + 1 > b_.size()) rehash(b_.size() * 2);
        for (Node* n = b_[idx(k, b_.size())].get(); n; n = n->next.get())
            if (n->key == k) { n->val = std::move(v); return false; }
        auto& head = b_[idx(k, b_.size())];
        head = std::unique_ptr<Node>(new Node{std::move(k), std::move(v), std::move(head)});
        ++size_;
        return true;
    }
    V* find(const K& k) noexcept {
        for (Node* n = b_[idx(k, b_.size())].get(); n; n = n->next.get())
            if (n->key == k) return &n->val;
        return nullptr;
    }
    bool erase(const K& k) {
        for (auto* p = &b_[idx(k, b_.size())]; *p; p = &(*p)->next)
            if ((*p)->key == k) { *p = std::move((*p)->next); --size_; return true; }
        return false;
    }
};
```

```cpp
// file: bench_skeleton.cpp  (C++20, GCC/Clang: uses inline asm as an optimizer barrier)
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <random>
#include <unordered_map>
#include <vector>

#include "flatmap.hpp"

template <class T> inline void keep(const T& v) { asm volatile("" : : "r,m"(v) : "memory"); }

// Median of `reps` timed runs of f(), in nanoseconds per call of f().
template <class F> double median_ns(F&& f, int reps) {
    std::vector<double> t;
    f();  // warm-up: page faults, cold caches, lazy allocation
    for (int i = 0; i < reps; ++i) {
        const auto a = std::chrono::steady_clock::now();
        f();
        const auto b = std::chrono::steady_clock::now();
        t.push_back(std::chrono::duration<double, std::nano>(b - a).count());
    }
    std::sort(t.begin(), t.end());
    return t[t.size() / 2];
}

template <class Map> void run(const char* name, std::size_t n, const std::vector<int>& keys, const std::vector<int>& miss) {
    Map m;
    for (std::size_t i = 0; i < n; ++i) m.insert_or_assign(keys[i], static_cast<int>(i));
    auto hit = [&] { long s = 0; for (int k : keys) { auto* p = m.find(k); s += p ? *p : 0; } keep(s); };
    auto mis = [&] { long s = 0; for (int k : miss) { auto* p = m.find(k); s += p ? *p : 0; } keep(s); };
    std::printf("%-12s n=%zu hit %.2f ns/op  miss %.2f ns/op\n", name, n,
                median_ns(hit, 15) / static_cast<double>(keys.size()), median_ns(mis, 15) / static_cast<double>(miss.size()));
}

struct StdAdapter : std::unordered_map<int, int> {  // give std the same interface
    void insert_or_assign(int k, int v) { (*this)[k] = v; }
    int* find(int k) { auto it = std::unordered_map<int, int>::find(k); return it == end() ? nullptr : &it->second; }
};

int main() {
    for (std::size_t n : {1u << 10, 1u << 14, 1u << 18, 1u << 22}) {  // pick sizes relative to YOUR cache sizes
        std::mt19937 rng(42);
        std::vector<int> keys(n), miss(n);
        for (auto& k : keys) k = static_cast<int>(rng() & 0x3fffffff);          // keys in [0, 2^30)
        for (auto& k : miss) k = static_cast<int>(rng() | 0x40000000u) & 0x7fffffff;  // disjoint range: guaranteed misses
        run<FlatMap<int, int>>("FlatMap", n, keys, miss);
        run<StdAdapter>("unordered_map", n, keys, miss);
    }
}
```
