## Retrieval answers

1. Ranking: CI workflow, Makefile, README, chat message. CI runs on every change, so it cannot silently rot for long, and it shows services and environment variables. A chat message is least reliable: unversioned, unreviewed, possibly describing someone's personal setup. Caveat: CI may differ from local development (for example it may use a container you do not), so CI tells you what is verified and the README may tell you what is convenient.
2. `/api/v1/items/{id}`. With `id=abc` and `id: int`, validation rejects the request with 422 before the endpoint body runs.
3. Capabilities are declared in `db/access.php`; at runtime `require_capability()` (throws) or `has_capability()` (returns bool) checks them. `require_login()` establishes an authenticated user (optionally with course/activity access); `require_capability()` checks that this user holds a specific permission in a specific context. Passing the first does not imply the second.
4. (a) Whether the same two tests fail on a clean checkout without your change; (b) whether they fail identically on a second run (flakiness); (c) whether they depend on something your environment lacks (services, credentials, network).
5. `os.environ["X"]` raises `KeyError` when unset; `.get("X")` returns `None` or the supplied default. The first marks a required variable, the second an optional one, which is the classification the inventory needs. The first also fails at the point of use, which may be request time rather than startup.
6. Yes; router-level dependencies apply to every route on the router. Do not assume a strict ordering between parameter validation and dependency execution: FastAPI solves parameters and dependencies together and reports validation errors as 422. If order matters to you, test it (VERIFY: three-line app, one request with both a bad parameter and a bad token).
7. AJAX/external functions: `db/services.php`; scheduled and ad hoc tasks: `db/tasks.php` (classes in `classes/task/`); event observers: `db/events.php`; CLI scripts: `admin/cli/` (no `db/` file). Web service endpoints reuse the external function declarations in `db/services.php`.
8. Change frequency per file, i.e. where work and risk concentrate. Distorted by lockfiles and generated files, mass reformat/rename commits, vendored dependencies, and translation files.
9. (a) The editor changed line endings or reformatted: revert and re-apply only the fix; fix the editor setting. (b) A formatter ran over the file: same. (c) An unrelated or generated file was staged: `git restore --staged <file>`, inspect `git status`. (d) The fix really is large: then it is not the smallest change; reconsider or split it.
10. The prefixed form scopes the variable to one command so it cannot persist in the shell and hide a missing-variable problem later.
11. Search the last path segment in quotes; search `include_router` and `prefix=`; read the route from `/openapi.json` or a printed `app.routes`; read what the tests call; `git log -S"orders"`.
12. Blast radius: the set of behaviours that can change when you change this code. Estimate with find-usages/grep of callers (including string-based callbacks and templates) and the tests that exercise those callers (a coverage run over the changed lines helps); also consider who consumes any data the code writes.

## Challenge reference solution (Section 8)

Known misleading case (comment this in your code): a CI line such as `run: pytest --cov && coverage report` is reported as one whole "command", including text that is not the test invocation; and a `test:` target that only echoes would be reported as documented. Documented means declared, not correct.

Alternatives: parse YAML properly (needs a dependency; the stdlib has no YAML parser, so rejected under the constraint), or report only file paths and let the human read them (never misleading, less useful). The line-regex approach trades precision for zero dependencies; the `confidence` field is how you stay honest about it.

```python
"""Reference solution for Lesson 0.1 challenge: infer how a repo's tests are run. Python 3.12+."""
from __future__ import annotations

import re
import unittest
from dataclasses import dataclass
from pathlib import Path
import tempfile

MAKE_TEST_RE = re.compile(r"^test\s*:", re.MULTILINE)
CI_CMD_RE = re.compile(r"^\s*-?\s*(?:run:\s*)?(?P<cmd>[^#\n]*\b(?:pytest|phpunit|tox)\b[^#\n]*)$", re.MULTILINE)


@dataclass(frozen=True)
class Candidate:
    command: str
    evidence: str
    confidence: str  # "documented" or "inferred"


def _read(p: Path) -> str:
    try:
        return p.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return ""


def infer_test_commands(root: Path) -> list[Candidate]:
    documented: list[Candidate] = []
    inferred: list[Candidate] = []
    makefile = root / "Makefile"
    if makefile.is_file() and MAKE_TEST_RE.search(_read(makefile)):
        documented.append(Candidate("make test", "Makefile: target 'test'", "documented"))
    wf_dir = root / ".github" / "workflows"
    if wf_dir.is_dir():
        for wf in sorted(wf_dir.glob("*.y*ml")):
            for m in CI_CMD_RE.finditer(_read(wf)):
                cmd = m["cmd"].strip()
                if cmd and not cmd.startswith(("pip ", "name:", "uses:")):
                    documented.append(Candidate(cmd, f"{wf.relative_to(root).as_posix()}: CI step", "documented"))
    if "[tool.pytest" in _read(root / "pyproject.toml") or (root / "pytest.ini").is_file():
        inferred.append(Candidate("pytest", "pytest configuration present", "inferred"))
    for name in ("phpunit.xml", "phpunit.xml.dist"):
        if (root / name).is_file():
            inferred.append(Candidate("vendor/bin/phpunit", f"{name} present", "inferred"))
            break
    if (root / "tox.ini").is_file():
        inferred.append(Candidate("tox", "tox.ini present", "inferred"))
    seen: set[str] = set()
    out = []
    for c in documented + inferred:
        if c.command not in seen:
            seen.add(c.command)
            out.append(c)
    return out


class InferTests(unittest.TestCase):
    def setUp(self):
        self._t = tempfile.TemporaryDirectory()
        self.addCleanup(self._t.cleanup)
        self.root = Path(self._t.name)

    def test_empty(self):
        self.assertEqual(infer_test_commands(self.root), [])

    def test_documented_before_inferred_and_deduped(self):
        (self.root / "Makefile").write_text("test:\n\tpytest\n")
        (self.root / "pytest.ini").write_text("[pytest]\n")
        (self.root / ".github/workflows").mkdir(parents=True)
        (self.root / ".github/workflows/ci.yml").write_text(
            "steps:\n  - run: pip install -e .\n  - run: pytest -q\n")
        cmds = infer_test_commands(self.root)
        self.assertEqual([c.command for c in cmds], ["make test", "pytest -q", "pytest"])
        self.assertEqual([c.confidence for c in cmds], ["documented", "documented", "inferred"])

    def test_phpunit_dist(self):
        (self.root / "phpunit.xml.dist").write_text("<phpunit/>")
        self.assertEqual(infer_test_commands(self.root)[0].command, "vendor/bin/phpunit")

    def test_makefile_without_test_target_ignored(self):
        (self.root / "Makefile").write_text("build:\n\techo hi\n")
        self.assertEqual(infer_test_commands(self.root), [])


if __name__ == "__main__":
    unittest.main()
```

## Project reference solution: `repo_map.py`

Design decisions. Scanners are pure functions of `(path, text)`; walking is isolated in `iter_files`. Ignored directories are pruned in place from `dirnames`, which prevents descent (cheaper and safer than filtering afterwards). Symlinks are skipped for directories and files, so the scan cannot leave the root. `errors="replace"` avoids crashes on bad bytes. Output is sorted for determinism.

Known limitations (your LIMITATIONS section should contain at least four of these): line regexes miss multi-line decorators and dynamic route registration; dynamically built env names are invisible; `pydantic-settings` fields are not detected; commented-out code still matches; `truncated` is set when `file_count >= max_files` even if the repository has exactly `max_files` files; files over 1 MB are skipped silently; `$CFG` counts include comments; `$_SERVER[...]` keys such as `REQUEST_URI` are reported as environment variables though they are request metadata (a stricter version drops `$_SERVER`).

```python
#!/usr/bin/env python3
"""repo_map.py - read-only orientation report for an unfamiliar repository.

Python 3.12+, standard library only. Never executes or imports repository code,
never writes inside the target, never follows symlinks.

Usage:
    python3 repo_map.py PATH [--json] [--max-files N]
"""
from __future__ import annotations

import argparse
import json
import os
import re
import sys
from collections import Counter, defaultdict
from dataclasses import dataclass, field
from pathlib import Path

IGNORE_DIRS = frozenset({
    ".git", ".hg", ".svn", "node_modules", "vendor", "__pycache__", ".venv", "venv",
    ".tox", ".mypy_cache", ".pytest_cache", ".ruff_cache", "dist", "build", ".idea", ".vscode",
})
SCAN_SUFFIXES = frozenset({".py", ".php"})
MAX_SCAN_BYTES = 1_000_000

# basename -> human label
MARKER_BASENAMES = {
    "pyproject.toml": "python project config",
    "requirements.txt": "python requirements",
    "setup.py": "python setup (legacy)",
    "setup.cfg": "python setup/tool config",
    "tox.ini": "tox config",
    "pytest.ini": "pytest config",
    "conftest.py": "pytest fixtures",
    "alembic.ini": "alembic migrations",
    "composer.json": "php dependencies",
    "phpunit.xml": "phpunit config",
    "phpunit.xml.dist": "phpunit config",
    "behat.yml": "behat config",
    "Makefile": "make targets",
    "Dockerfile": "container image",
    "docker-compose.yml": "compose services",
    "docker-compose.yaml": "compose services",
    "compose.yaml": "compose services",
    ".env.example": "documented env vars",
    ".env.sample": "documented env vars",
    "config-dist.php": "moodle config template",
    "config.php": "moodle/php config",
    "version.php": "moodle version / plugin metadata",
    "README.md": "readme",
    "CONTRIBUTING.md": "contribution rules",
    "package.json": "node project",
    ".pre-commit-config.yaml": "pre-commit hooks",
}
MOODLE_DB_FILES = {"access.php", "services.php", "events.php", "tasks.php", "install.xml", "upgrade.php"}

ROUTE_RE = re.compile(
    r"""^\s*@(?P<obj>\w+)\.(?P<verb>get|post|put|patch|delete|head|options)\(\s*(?P<q>["'])(?P<path>[^"']*)(?P=q)""")
APP_RE = re.compile(r"""^\s*(?P<name>\w+)\s*(?::[^=]+)?=\s*(?P<kind>FastAPI|APIRouter)\(""")
ENV_PATTERNS = [
    re.compile(r"""os\.environ(?:\.get)?\s*[\[(]\s*["'](?P<n>[A-Za-z_][A-Za-z0-9_]*)["']"""),
    re.compile(r"""os\.getenv\(\s*["'](?P<n>[A-Za-z_][A-Za-z0-9_]*)["']"""),
    re.compile(r"""(?<![\w.])getenv\(\s*["'](?P<n>[A-Za-z_][A-Za-z0-9_]*)["']"""),
    re.compile(r"""\$_(?:ENV|SERVER)\[\s*["'](?P<n>[A-Za-z_][A-Za-z0-9_]*)["']\s*\]"""),
]
CFG_RE = re.compile(r"""\$CFG->(?P<n>[A-Za-z_][A-Za-z0-9_]*)""")
PLUGIN_RE = re.compile(r"""\$plugin->(?P<k>component|version|requires|release)\s*=\s*["']?(?P<v>[^"';\s]+)""")
TEST_FILE_RE = re.compile(r"(^test_.*\.py$|.*_test\.py$|.*_test\.php$|.*\.feature$)")


@dataclass
class Report:
    root: str
    file_count: int = 0
    truncated: bool = False
    extensions: dict[str, int] = field(default_factory=dict)
    markers: dict[str, list[str]] = field(default_factory=dict)
    apps: list[dict] = field(default_factory=list)
    routes: list[dict] = field(default_factory=list)
    env_vars: dict[str, list[str]] = field(default_factory=dict)
    moodle_cfg: dict[str, int] = field(default_factory=dict)
    moodle_plugins: list[dict] = field(default_factory=list)
    moodle_db_files: dict[str, list[str]] = field(default_factory=dict)
    test_files: list[str] = field(default_factory=list)
    ci_files: list[str] = field(default_factory=list)


def iter_files(root: Path, max_files: int | None = None):
    """Yield (relative_path, truncated_flag_holder) lazily; sorted for determinism, no symlink following."""
    count = 0
    for dirpath, dirnames, filenames in os.walk(root, followlinks=False):
        dirnames[:] = sorted(d for d in dirnames if d not in IGNORE_DIRS
                             and not os.path.islink(os.path.join(dirpath, d)))
        for name in sorted(filenames):
            full = Path(dirpath, name)
            if full.is_symlink():
                continue
            if max_files is not None and count >= max_files:
                return
            count += 1
            yield full.relative_to(root)


def read_text(path: Path) -> str | None:
    try:
        if path.stat().st_size > MAX_SCAN_BYTES:
            return None
        return path.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return None


def scan_python(rel: Path, text: str, report: Report) -> None:
    for lineno, line in enumerate(text.splitlines(), 1):
        m = APP_RE.match(line)
        if m:
            report.apps.append({"file": rel.as_posix(), "line": lineno, "name": m["name"], "kind": m["kind"]})
        m = ROUTE_RE.match(line)
        if m:
            report.routes.append({"file": rel.as_posix(), "line": lineno, "object": m["obj"],
                                  "method": m["verb"].upper(), "path": m["path"]})


def scan_env(rel: Path, text: str, env: dict[str, list[str]], cfg: Counter) -> None:
    for lineno, line in enumerate(text.splitlines(), 1):
        for pat in ENV_PATTERNS:
            for m in pat.finditer(line):
                env[m["n"]].append(f"{rel.as_posix()}:{lineno}")
        if rel.suffix == ".php":
            for m in CFG_RE.finditer(line):
                cfg[m["n"]] += 1


def parse_plugin_version(rel: Path, text: str) -> dict | None:
    info = {m["k"]: m["v"] for m in PLUGIN_RE.finditer(text)}
    if "component" not in info:
        return None
    return {"file": rel.as_posix(), **info}


def build_report(root: Path, max_files: int | None = 20000) -> Report:
    root = root.resolve()
    report = Report(root=str(root))
    ext: Counter = Counter()
    markers: dict[str, list[str]] = defaultdict(list)
    env: dict[str, list[str]] = defaultdict(list)
    cfg: Counter = Counter()
    db_files: dict[str, list[str]] = defaultdict(list)
    for rel in iter_files(root, max_files):
        report.file_count += 1
        ext[rel.suffix.lower() or "(none)"] += 1
        posix = rel.as_posix()
        if rel.name in MARKER_BASENAMES:
            markers[rel.name].append(posix)
        if rel.parts[:2] == (".github", "workflows") or rel.name in {".gitlab-ci.yml", "Jenkinsfile", "azure-pipelines.yml"}:
            report.ci_files.append(posix)
        if TEST_FILE_RE.match(rel.name):
            report.test_files.append(posix)
        if rel.parent.name == "db" and rel.name in MOODLE_DB_FILES:
            db_files[rel.name].append(posix)
        if rel.suffix in SCAN_SUFFIXES:
            text = read_text(root / rel)
            if text is None:
                continue
            if rel.suffix == ".py":
                scan_python(rel, text, report)
            scan_env(rel, text, env, cfg)
            if rel.name == "version.php":
                info = parse_plugin_version(rel, text)
                if info:
                    report.moodle_plugins.append(info)
    if max_files is not None and report.file_count >= max_files:
        report.truncated = True
    report.extensions = dict(ext.most_common())
    report.markers = dict(sorted(markers.items()))
    report.env_vars = {k: v for k, v in sorted(env.items())}
    report.moodle_cfg = dict(cfg.most_common(15))
    report.moodle_db_files = dict(sorted(db_files.items()))
    return report


def render_markdown(r: Report) -> str:
    out = [f"# Repo map: {r.root}", "", f"Files scanned: {r.file_count}" + (" (TRUNCATED)" if r.truncated else ""), ""]
    out += ["## Extensions"] + [f"- {k}: {v}" for k, v in list(r.extensions.items())[:10]] + [""]
    out += ["## Marker files"] + [f"- {k} ({MARKER_BASENAMES[k]}): {', '.join(v[:5])}" for k, v in r.markers.items()] + [""]
    out += ["## CI files"] + [f"- {p}" for p in r.ci_files] + [""]
    out += ["## FastAPI apps / routers"] + [f"- {a['file']}:{a['line']} {a['name']} = {a['kind']}()" for a in r.apps] + [""]
    out += ["## Routes (decorator heuristic)"] + [
        f"- {x['method']} {x['path']}  <- {x['file']}:{x['line']} ({x['object']})" for x in r.routes] + [""]
    out += ["## Environment variables referenced"] + [f"- {k}: {', '.join(v[:3])}" for k, v in r.env_vars.items()] + [""]
    out += ["## Moodle plugins (version.php)"] + [
        f"- {p['component']} version={p.get('version', '?')} ({p['file']})" for p in r.moodle_plugins] + [""]
    out += ["## Moodle db/ files"] + [f"- {k}: {', '.join(v[:5])}" for k, v in r.moodle_db_files.items()] + [""]
    out += ["## Most-used $CFG settings"] + [f"- {k}: {v}" for k, v in r.moodle_cfg.items()] + [""]
    out += [f"## Test files ({len(r.test_files)})"] + [f"- {p}" for p in r.test_files[:20]] + [""]
    return "\n".join(out)


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="Read-only repository orientation report.")
    ap.add_argument("path", type=Path)
    ap.add_argument("--json", action="store_true", help="emit JSON instead of Markdown")
    ap.add_argument("--max-files", type=int, default=20000)
    args = ap.parse_args(argv)
    if not args.path.is_dir():
        print(f"error: {args.path} is not a directory", file=sys.stderr)
        return 2
    report = build_report(args.path, args.max_files)
    print(json.dumps(report.__dict__, indent=2) if args.json else render_markdown(report))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

def write(root: Path, rel: str, text: str = "") -> None:

Mutation checks to do by hand: remove `followlinks=False` and the `is_symlink` checks, and `test_symlink_not_followed` must fail (on Linux); remove the `IGNORE_DIRS` pruning, and `test_ignored_dirs_are_skipped` must fail. `os.symlink` may need privileges on Windows; guard with `unittest.skipIf` and say so.

Trade-off against `ast`: for `.py`, `ast.parse` removes false positives from comments and strings and handles multi-line decorators, but fails the whole file on a syntax error (for example code written for a newer Python than your interpreter) and cannot help with PHP. A defensible hybrid is `ast` first with regex fallback; measure on your own repositories before adopting.

## Dossier: reference skeleton and scoring notes

Headings: 1 Sources read (file, claim, trust class); 2 Setup log (command, result); 3 Deviation log (step, symptom, resolution); 4 Baseline (command, counts, duration, run 1 vs run 2); 5 Trace table (step, file:line, what happens, guard/validation/data marker); 6 Config inventory (name, source file:line, class, where a safe local value comes from); 7 Test map (module, tests, command, gaps); 8 Reproduction (failing output, diff, three-level verification); 9 Open questions (blocking first).

Scoring notes. Trace accuracy (15): sample five claims; each wrong or unverifiable claim costs 3; an explicit "unknown" costs nothing. Config inventory (8): full marks need at least one item classified dangerous with a reason, or an explicit statement that none was found and how that was checked. Reproduction and change (12): 4 for a failure for the right reason (the assertion message was read), 3 for a justified smallest change, 3 for three-level verification, 2 for a baseline delta. A dossier whose commands were copied from the README rather than run scores 0 in the setup row.

Worked-example follow-up: the `max(0, ...)` clamp is correct only if the business rule is "a discount cannot exceed the subtotal". If an over-discount is invalid input, the right change is validation at the boundary (a 4xx response). The reader should record this as an open question in the PR instead of deciding silently (Lesson 0.4).
