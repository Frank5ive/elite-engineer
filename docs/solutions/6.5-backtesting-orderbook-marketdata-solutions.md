## A. Retrieval answers (section 7)

1. Look-ahead: using information unavailable at decision time (trading at a close using that close's signal). Survivorship: dataset contains only assets that still exist, e.g. an index-constituent list as of today applied to 2010. Data snooping: choosing the best of many tried parameter sets or strategies and reporting only it.
2. `signal[t]` computed from the close at t multiplies the return into t, so the position earns a move it already saw. Minimal fix: shift the signal by one bar, `pnl[t] = signal[t-1] * ret[t]` (and cross-check with an event-driven engine).
3. Not plausible. The best of 50 noise strategies is a selection maximum; expect OOS Sharpe near 0 (or slightly negative after costs). Check: repeat on many driftless seeds, select in-sample, evaluate OOS (section 4.3: mean in-sample best +0.96, mean OOS -0.15 over 40 seeds with 93 candidates).
4. Protects against fitting noise inside a training window (each test segment is unseen by that window's fit). Does not protect against: regime change that never repeats; the researcher choosing the method/window sizes after seeing all the data; trying many strategies and reporting the best walk-forward result; survivorship or look-ahead in the data itself.
5. Assumption: each trade is one side at 3 bps, no other costs, 1x gross. 4 trades/day * 3 bps = 12 bps/day; * 252 = 3,024 bps = about 30.2% of capital per year. If a "trade" means a round trip (two sides), double it to about 60.5%. State the assumption; either way the signal must earn more than that gross.
6. Such a strategy earns a small steady premium and suffers rare large losses; a sample without a crash shows low volatility and a high Sharpe. Sharpe treats volatility as risk symmetrically and is blind to skew and tail risk; report drawdown, skew/kurtosis and stress losses too.
7. Invariants: (1) no empty levels; (2) `Level::total` equals sum of quantities; (3) index and lists agree both ways; (4) never crossed after any operation; (5) FIFO within a level; (6) all quantities > 0. "Empty level left in map" is detected by `check_invariants()` after each operation in the randomised test (also by best_bid returning a price with depth 0). Mutation check run while writing this: removing the `opp.erase(lvl_it)` line made the randomised test hang (the matcher loops forever on an empty best level; the timeout caught it), and removing the `total` update in cancel gave "invariant violated seed 1 step 45".
8. add sell 101x5 (id1); add sell 101x5 (id2); buy 101x7 (id3). Trades: (taker 3, maker 1, 101, 5), (taker 3, maker 2, 101, 2). Book: asks 101: id2 with qty 3; no bids; id3 fully filled and does not rest.
9. Cancel id2 (book empties; ask side now empty). Buy 101x10 (id4): no trades; rests as bid 101 x10. Best bid 101, no ask.
10. Time priority rewards the queue position earned by committing the original size. Increasing size would let a participant claim priority for liquidity they did not offer at that time; reducing size only removes liquidity and disadvantages nobody behind them. (Convention in many venues; VERIFY the venue's rules.)
11. `std::list` erase invalidates only iterators/references to the erased element; others stay valid, so a locator stays valid until its own order is erased. Breaks if you use `std::vector`/`std::deque` (erase/insert shifts elements) or if you forget to erase the index entry when the order leaves the list (dangling iterator).
12. Wall-clock time; platform-dependent RNG distributions or unseeded RNG; iteration over unordered containers that affects output; thread interleaving; uninitialised memory; floating-point summation order. Test: replay the same input twice (and on a different compiler/build) and compare a checksum of all outputs; run under sanitizers/valgrind for uninitialised reads.

`order_book.hpp` (C++20):

```cpp
// C++20. Price-time priority limit order book. Single-threaded, deterministic.
#pragma once
#include <algorithm>
#include <cstdint>
#include <iterator>
#include <functional>
#include <list>
#include <map>
#include <optional>
#include <unordered_map>
#include <vector>

namespace ob {

using OrderId = std::uint64_t;
using Price   = std::int64_t;   // integer ticks; never floating point
using Qty     = std::int64_t;

enum class Side : std::uint8_t { Buy, Sell };

struct Trade {
    OrderId taker;
    OrderId maker;
    Price   price;   // maker's resting price
    Qty     qty;
    bool operator==(const Trade&) const = default;
};

class OrderBook {
public:
    // Returns trades produced. Any unfilled remainder rests at `price`.
    // Rejects (returns nullopt) on duplicate id, qty <= 0.
    std::optional<std::vector<Trade>> add_limit(OrderId id, Side side, Price price, Qty qty);

    // Executes against the book; unfilled remainder is discarded (IOC semantics).
    std::optional<std::vector<Trade>> add_market(OrderId id, Side side, Qty qty);

    bool cancel(OrderId id);

    // Reduce qty in place (keeps queue position). Anything else is cancel + new
    // (loses priority). new_qty <= 0 or unknown id -> nullopt.
    std::optional<std::vector<Trade>> modify(OrderId id, Price new_price, Qty new_qty);

    std::optional<Price> best_bid() const;
    std::optional<Price> best_ask() const;
    Qty depth_at(Side side, Price price) const;
    std::size_t order_count() const { return index_.size(); }

    // Test/debug use: verifies invariants 1-4 and 6 of the lesson plus index consistency.
    bool check_invariants() const;

private:
    struct Order { OrderId id; Qty qty; };
    struct Level { std::list<Order> queue; Qty total = 0; };
    struct Locator { Side side; Price price; std::list<Order>::iterator it; };

    using Bids = std::map<Price, Level, std::greater<Price>>;
    using Asks = std::map<Price, Level, std::less<Price>>;

    template <class BookSide>
    Qty match(OrderId taker, BookSide& opp, bool buy, Price limit, bool has_limit,
              Qty qty, std::vector<Trade>& out);
    void rest(OrderId id, Side side, Price price, Qty qty);

    Bids bids_;
    Asks asks_;
    std::unordered_map<OrderId, Locator> index_;
};

template <class BookSide>
Qty OrderBook::match(OrderId taker, BookSide& opp, bool buy, Price limit, bool has_limit,
                     Qty qty, std::vector<Trade>& out) {
    while (qty > 0 && !opp.empty()) {
        auto lvl_it = opp.begin();
        Price p = lvl_it->first;
        if (has_limit && (buy ? p > limit : p < limit)) break;
        Level& lvl = lvl_it->second;
        while (qty > 0 && !lvl.queue.empty()) {
            Order& maker = lvl.queue.front();
            Qty fill = std::min(qty, maker.qty);
            out.push_back({taker, maker.id, p, fill});
            qty -= fill; maker.qty -= fill; lvl.total -= fill;
            if (maker.qty == 0) { index_.erase(maker.id); lvl.queue.pop_front(); }
        }
        if (lvl.queue.empty()) opp.erase(lvl_it);
    }
    return qty;
}

inline void OrderBook::rest(OrderId id, Side side, Price price, Qty qty) {
    auto place = [&](auto& book) {
        Level& lvl = book[price];
        lvl.queue.push_back({id, qty});
        lvl.total += qty;
        index_[id] = {side, price, std::prev(lvl.queue.end())};
    };
    if (side == Side::Buy) place(bids_); else place(asks_);
}

inline std::optional<std::vector<Trade>> OrderBook::add_limit(OrderId id, Side side, Price price, Qty qty) {
    if (qty <= 0 || index_.contains(id)) return std::nullopt;
    std::vector<Trade> out;
    Qty left = (side == Side::Buy) ? match(id, asks_, true, price, true, qty, out)
                                   : match(id, bids_, false, price, true, qty, out);
    if (left > 0) rest(id, side, price, left);
    return out;
}

inline std::optional<std::vector<Trade>> OrderBook::add_market(OrderId id, Side side, Qty qty) {
    if (qty <= 0 || index_.contains(id)) return std::nullopt;
    std::vector<Trade> out;
    if (side == Side::Buy) match(id, asks_, true, 0, false, qty, out);
    else                   match(id, bids_, false, 0, false, qty, out);
    return out;
}

inline bool OrderBook::cancel(OrderId id) {
    auto it = index_.find(id);
    if (it == index_.end()) return false;
    Locator loc = it->second;
    auto erase_from = [&](auto& book) {
        auto lvl_it = book.find(loc.price);
        lvl_it->second.total -= loc.it->qty;
        lvl_it->second.queue.erase(loc.it);
        if (lvl_it->second.queue.empty()) book.erase(lvl_it);
    };
    if (loc.side == Side::Buy) erase_from(bids_); else erase_from(asks_);
    index_.erase(it);
    return true;
}

inline std::optional<std::vector<Trade>> OrderBook::modify(OrderId id, Price new_price, Qty new_qty) {
    auto it = index_.find(id);
    if (it == index_.end() || new_qty <= 0) return std::nullopt;
    Locator loc = it->second;
    if (new_price == loc.price && new_qty <= loc.it->qty) {
        auto adjust = [&](auto& book) { book.find(loc.price)->second.total -= loc.it->qty - new_qty; };
        if (loc.side == Side::Buy) adjust(bids_); else adjust(asks_);
        loc.it->qty = new_qty;
        return std::vector<Trade>{};
    }
    Side side = loc.side;
    cancel(id);
    return add_limit(id, side, new_price, new_qty);
}

inline std::optional<Price> OrderBook::best_bid() const {
    return bids_.empty() ? std::nullopt : std::optional<Price>(bids_.begin()->first);
}
inline std::optional<Price> OrderBook::best_ask() const {
    return asks_.empty() ? std::nullopt : std::optional<Price>(asks_.begin()->first);
}
inline Qty OrderBook::depth_at(Side side, Price price) const {
    if (side == Side::Buy) { auto i = bids_.find(price); return i == bids_.end() ? 0 : i->second.total; }
    auto i = asks_.find(price); return i == asks_.end() ? 0 : i->second.total;
}

inline bool OrderBook::check_invariants() const {
    std::size_t seen = 0;
    auto check_side = [&](const auto& book, Side side) {
        for (const auto& [price, lvl] : book) {
            if (lvl.queue.empty()) return false;                    // inv 1
            Qty sum = 0;
            for (auto it = lvl.queue.begin(); it != lvl.queue.end(); ++it) {
                if (it->qty <= 0) return false;                     // inv 6
                sum += it->qty;
                auto f = index_.find(it->id);                       // inv 3
                if (f == index_.end() || f->second.side != side || f->second.price != price ||
                    f->second.it != it) return false;
                ++seen;
            }
            if (sum != lvl.total) return false;                     // inv 2
        }
        return true;
    };
    if (!check_side(bids_, Side::Buy) || !check_side(asks_, Side::Sell)) return false;
    if (seen != index_.size()) return false;                        // inv 3 (reverse direction)
    if (!bids_.empty() && !asks_.empty() && bids_.begin()->first >= asks_.begin()->first) return false;  // inv 4
    return true;                                                    // inv 5 (FIFO) is covered by the reference-model test
}

}  // namespace ob
```

`test_random.cpp` (randomised comparison with a naive model, invariants after every event, 20 seeds x 10,000 events; passed, also under ASan/UBSan):

```cpp
// Randomised comparison against a naive reference model. C++20.
#include "order_book.hpp"
#include <cstdio>
#include <cstdlib>
#include <random>
#include <vector>
using namespace ob;

struct Naive {                       // obviously-correct, O(n) per operation
    struct O { OrderId id; Side side; Price price; Qty qty; std::uint64_t seq; };
    std::vector<O> orders; std::uint64_t seq = 0;
    std::vector<Trade> add_limit(OrderId id, Side s, Price p, Qty q) {
        std::vector<Trade> out;
        while (q > 0) {
            int best = -1;
            for (int i = 0; i < (int)orders.size(); ++i) {
                const O& o = orders[i];
                if (o.side == s) continue;
                bool crosses = (s == Side::Buy) ? o.price <= p : o.price >= p;
                if (!crosses) continue;
                if (best < 0) { best = i; continue; }
                const O& b = orders[best];
                bool better = (s == Side::Buy) ? (o.price < b.price) : (o.price > b.price);
                if (better || (o.price == b.price && o.seq < b.seq)) best = i;
            }
            if (best < 0) break;
            Qty f = std::min(q, orders[best].qty);
            out.push_back({id, orders[best].id, orders[best].price, f});
            q -= f; orders[best].qty -= f;
            if (orders[best].qty == 0) orders.erase(orders.begin() + best);
        }
        if (q > 0) orders.push_back({id, s, p, q, seq++});
        return out;
    }
    bool cancel(OrderId id) {
        for (std::size_t i = 0; i < orders.size(); ++i) if (orders[i].id == id) { orders.erase(orders.begin() + i); return true; }
        return false;
    }
    Qty depth(Side s, Price p) const { Qty t = 0; for (auto& o : orders) if (o.side == s && o.price == p) t += o.qty; return t; }
};

int main() {
    for (std::uint64_t seed = 1; seed <= 20; ++seed) {
        std::mt19937_64 g(seed);
        OrderBook b; Naive n; OrderId next = 1; std::vector<OrderId> ids;
        for (int i = 0; i < 10000; ++i) {
            if (g() % 100 < 65 || ids.empty()) {
                Side s = (g() & 1) ? Side::Buy : Side::Sell;
                Price p = 100 + (Price)(g() % 11) - 5; Qty q = 1 + (Qty)(g() % 20);
                auto t1 = *b.add_limit(next, s, p, q); auto t2 = n.add_limit(next, s, p, q);
                if (t1 != t2) { std::printf("trade mismatch seed %llu step %d\n", (unsigned long long)seed, i); return 1; }
                ids.push_back(next++);
            } else {
                OrderId id = ids[g() % ids.size()];           // may be stale
                if (b.cancel(id) != n.cancel(id)) { std::printf("cancel mismatch\n"); return 1; }
            }
            if (!b.check_invariants()) { std::printf("invariant violated seed %llu step %d\n", (unsigned long long)seed, i); return 1; }
            for (Price p = 95; p <= 105; ++p)
                if (b.depth_at(Side::Buy, p) != n.depth(Side::Buy, p) || b.depth_at(Side::Sell, p) != n.depth(Side::Sell, p)) {
                    std::printf("depth mismatch seed %llu step %d\n", (unsigned long long)seed, i); return 1; }
        }
    }
    std::puts("randomised comparison passed: 20 seeds x 10000 events");
}
```

`bench.cpp` (replay driver and benchmark skeleton; it prints the checksum on stdout and elapsed time on stderr; the repetition and statistics harness is yours to write per 4.6; the elapsed time it prints is not quoted anywhere in the lesson):

```cpp
// Replay/benchmark driver. Usage: ./bench N_EVENTS SEED
#include "order_book.hpp"
#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <random>
#include <vector>
using namespace ob;

struct Ev { int kind; OrderId id; Side side; Price price; Qty qty; };

// mt19937_64 output is specified by the standard; we avoid <random> distributions
// (their output is implementation-defined) and use modulo on raw words instead.
static std::vector<Ev> generate(std::size_t n, std::uint64_t seed) {
    std::mt19937_64 g(seed);
    std::vector<Ev> evs; evs.reserve(n);
    std::vector<OrderId> live;           // ids that may still be resting (may be stale)
    OrderId next = 1;
    for (std::size_t i = 0; i < n; ++i) {
        std::uint64_t r = g();
        unsigned k = r % 100;
        if (k < 60 || live.empty()) {    // add limit near 10000
            Side s = (g() & 1) ? Side::Buy : Side::Sell;
            Price p = 10000 + static_cast<Price>(g() % 21) - 10;
            evs.push_back({0, next, s, p, static_cast<Qty>(1 + g() % 100)});
            live.push_back(next++);
        } else if (k < 90) {             // cancel a random earlier id (may be stale)
            evs.push_back({1, live[g() % live.size()], Side::Buy, 0, 0});
        } else {                         // market order
            Side s = (g() & 1) ? Side::Buy : Side::Sell;
            evs.push_back({2, next++, s, 0, static_cast<Qty>(1 + g() % 100)});
        }
    }
    return evs;
}

int main(int argc, char** argv) {
    std::size_t n = argc > 1 ? std::strtoull(argv[1], nullptr, 10) : 1'000'000;
    std::uint64_t seed = argc > 2 ? std::strtoull(argv[2], nullptr, 10) : 1;
    auto evs = generate(n, seed);        // generation is OUTSIDE the timed region
    OrderBook b;
    std::uint64_t checksum = 1469598103934665603ULL, trades = 0;
    auto mix = [&](std::uint64_t v) { checksum = (checksum ^ v) * 1099511628211ULL; };
    auto t0 = std::chrono::steady_clock::now();
    for (const Ev& e : evs) {
        if (e.kind == 0) { auto t = b.add_limit(e.id, e.side, e.price, e.qty); for (auto& x : *t) { mix(x.maker); mix(x.price); mix(x.qty); ++trades; } }
        else if (e.kind == 1) mix(b.cancel(e.id));
        else { auto t = b.add_market(e.id, e.side, e.qty); for (auto& x : *t) { mix(x.maker); mix(x.price); mix(x.qty); ++trades; } }
        auto bb = b.best_bid(), ba = b.best_ask();
        if (bb && ba && *bb >= *ba) { std::puts("INVARIANT VIOLATED: crossed book"); return 1; }
    }
    auto t1 = std::chrono::steady_clock::now();
    double secs = std::chrono::duration<double>(t1 - t0).count();
    std::printf("events=%zu trades=%llu resting=%zu checksum=%llu\n", n, (unsigned long long)trades,
                b.order_count(), (unsigned long long)checksum);
    std::fprintf(stderr, "elapsed_s=%.6f (measure yourself; do not quote this as a general result)\n", secs);
}
```

Design notes and trade-offs: `std::map` + `std::list` + `unordered_map` is the simplest correct structure; each list node is an allocation (poor locality). Alternatives: price-indexed array of levels for bounded tick ranges (O(1) level lookup), intrusive lists with a pool allocator. ## E. Project reference: backtester

`quantlib/backtest.py`:

```python
"""Minimal event-driven backtester. Python 3.12+, stdlib only.
Timing convention: a decision made on bar t sees closes[0..t] only and is
filled at closes[t+1] (a crude one-bar-delay model; real fills differ)."""
from __future__ import annotations
import math
import random
from dataclasses import dataclass, field
from typing import Callable, Sequence

Strategy = Callable[[Sequence[float]], int]   # history (inclusive of t) -> target sign in {-1,0,1}


def synthetic_prices(n: int, seed: int, mu: float = 0.0, sigma: float = 0.01, p0: float = 100.0) -> list[float]:
    """Geometric random walk with constant per-bar drift mu and vol sigma (log-returns)."""
    rng = random.Random(seed)
    p, out = p0, [p0]
    for _ in range(n - 1):
        p *= math.exp(rng.gauss(mu, sigma))
        out.append(p)
    return out


@dataclass
class Config:
    initial_cash: float = 1_000_000.0
    unit: int = 1000                 # shares per unit of target position
    fee_bps: float = 0.0             # proportional fee, basis points of notional
    slip_bps: float = 0.0            # adverse price move on each fill, bps
    max_abs_units: int = 1           # hard position limit (risk control)
    bars_per_year: int = 252


@dataclass
class Result:
    equity: list[float]
    positions: list[int]
    n_fills: int
    costs_paid: float
    cfg: Config
    notes: list[str] = field(default_factory=list)


def run_backtest(closes: Sequence[float], strat: Strategy, cfg: Config) -> Result:
    cash, shares = cfg.initial_cash, 0
    equity = [cash]
    pos_hist = [0]
    n_fills, costs = 0, 0.0
    pending: int | None = None            # target decided on previous bar, fills now
    for t in range(1, len(closes)):
        px = closes[t]
        if pending is not None:
            target = max(-cfg.max_abs_units, min(cfg.max_abs_units, pending)) * cfg.unit
            dq = target - shares
            if dq != 0:
                fill_px = px * (1 + math.copysign(cfg.slip_bps / 1e4, dq))
                fee = abs(dq) * fill_px * cfg.fee_bps / 1e4
                cash -= dq * fill_px + fee
                costs += fee + abs(dq) * abs(fill_px - px)
                shares, n_fills = target, n_fills + 1
        equity.append(cash + shares * px)
        pos_hist.append(shares // cfg.unit)
        pending = strat(closes[: t + 1])          # slice ends at t: no future data visible
    return Result(equity, pos_hist, n_fills, costs, cfg)


def vectorized_pnl(closes: Sequence[float], strat: Strategy, unit: int) -> list[float]:
    """Cumulative P&L, zero costs, position limit +-1. Independent cross-check of the event engine.
    sig[k] is decided at close k; it is filled at close k+1 and earns the move k+1 -> k+2."""
    n = len(closes)
    sig = [strat(closes[: k + 1]) for k in range(n)]
    out, cum = [0.0], 0.0
    for t in range(1, n):
        held = sig[t - 2] if t >= 2 else 0
        cum += held * unit * (closes[t] - closes[t - 1])
        out.append(cum)
    return out


def sma_cross(fast: int, slow: int) -> Strategy:
    def f(h: Sequence[float]) -> int:
        if len(h) < slow:
            return 0
        a = sum(h[-fast:]) / fast
        b = sum(h[-slow:]) / slow
        return 1 if a > b else -1
    return f


def peeking_strategy(closes_full: Sequence[float]) -> Strategy:
    """DELIBERATELY WRONG: reads the next bar. For the look-ahead lab only."""
    def f(h: Sequence[float]) -> int:
        t = len(h) - 1
        if t + 2 >= len(closes_full):
            return 0
        # fill happens at close t+1, so the move the position earns is t+1 -> t+2
        return 1 if closes_full[t + 2] > closes_full[t + 1] else -1
    return f


# ---- metrics ----
def returns_from_equity(eq: Sequence[float]) -> list[float]:
    return [eq[i] / eq[i - 1] - 1 for i in range(1, len(eq))]


def sharpe(rets: Sequence[float], bars_per_year: int) -> float:
    n = len(rets)
    if n < 2:
        return float("nan")
    m = sum(rets) / n
    sd = math.sqrt(sum((r - m) ** 2 for r in rets) / (n - 1))
    return float("nan") if sd == 0 else m / sd * math.sqrt(bars_per_year)


def max_drawdown(eq: Sequence[float]) -> float:
    peak, mdd = eq[0], 0.0
    for v in eq:
        peak = max(peak, v)
        mdd = max(mdd, (peak - v) / peak)
    return mdd


LIMITATIONS = (
    "LIMITATIONS: (1) Fills assume you trade at the next bar's close plus a fixed bps slippage; "
    "no order book, queue position, partial fills or market impact. (2) Costs are constant-bps guesses, not measured. "
    "(3) Sharpe is estimated from one path; its standard error is large and it assumes roughly independent, "
    "identically distributed returns. (4) Data is synthetic or user-supplied; no survivorship, corporate-action "
    "or data-quality handling is performed. (5) If you tried several strategies or parameters, the best result "
    "is biased upward (data snooping). (6) A positive backtest is NOT evidence of future profit."
)


def report(res: Result, label: str, n_trials: int = 1) -> str:
    rets = returns_from_equity(res.equity)
    lines = [
        f"== {label} ==",
        f"bars={len(res.equity)}  fills={res.n_fills}  costs_paid={res.costs_paid:,.2f}",
        f"total_return={res.equity[-1] / res.equity[0] - 1:+.4%}  "
        f"sharpe(ann, rf=0)={sharpe(rets, res.cfg.bars_per_year):.3f}  "
        f"max_drawdown={max_drawdown(res.equity):.4%}",
        f"n_trials_considered={n_trials}",
        LIMITATIONS,
    ]
    return "\n".join(lines)
```

```python
import unittest
from quantlib.backtest import *

def held_positions(closes, strat, same_bar_leak: bool):
    """Position HELD DURING the move closes[t-1] -> closes[t], for t = 1..n-1.
    Honest: decided with data <= t-1. Leaky (the lab's flawed code): decided with data <= t."""
    out = []
    for t in range(1, len(closes)):
        out.append(strat(closes[: t + 1]) if same_bar_leak else strat(closes[:t]))
    return out

class T(unittest.TestCase):
    def mutated(self):
        c = synthetic_prices(300, seed=5)
        return c, c[:150] + [x * 1.7 for x in c[150:]]

    def test_mutation_detects_same_bar_leak(self):
        c, c2 = self.mutated()
        s = sma_cross(5, 20)
        # position held during the move INTO bar 150 must not depend on bar 150's close
        honest = lambda x: held_positions(x, s, False)[:150]   # moves into bars 1..150
        leaky = lambda x: held_positions(x, s, True)[:150]
        self.assertEqual(honest(c), honest(c2))
        self.assertNotEqual(leaky(c), leaky(c2))

    def test_engine_positions_do_not_depend_on_bar_k(self):
        c, c2 = self.mutated()
        a = run_backtest(c, sma_cross(5, 20), Config()); b = run_backtest(c2, sma_cross(5, 20), Config())
        # positions[k] is held after the fill at close k, decided from data <= k-1
        self.assertEqual(a.positions[:151], b.positions[:151])

if __name__ == "__main__": unittest.main()
```
