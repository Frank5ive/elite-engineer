## Section 7: Retrieval answers

1. Iterable: has `__iter__` returning an iterator. Iterator: has `__next__` and `__iter__` returning itself. A `list` is iterable, not an iterator (`iter(lst) is lst` is `False`). A file object is an iterator (`iter(f) is f`). `iter(x) is x` being `True` means one-shot.
2. `[1, 2, 3] []` and `['1', '2'] []`. Generators and `map` objects are iterators and are exhausted after the first `list`.
3. Calling it runs no body code; it creates a generator object. Execution happens on `next()`. `StopIteration.value` carries the generator's `return` value; `yield from` uses it as the value of the expression.
4. Prints `1`, then `got hi`, then `2` (the `send` prints inside the generator before returning the value that `print` outputs).
5. `groupby` only groups consecutive items with equal keys, and does not buffer. Unsorted input yields repeated keys. `groupby("aabaa")` gives `a:2, b:1, a:2`.
6. The exception is thrown into the generator at the `yield`; code after `yield` is skipped because the exception propagates out of the generator. Fix: `try: yield ... finally: cleanup`. Use `except`/`else` if you need different commit and rollback paths.
7. `__exit__` is called when the `with` block ends for any reason: normal exit, exception, `return`, `break`. Returning a truthy value suppresses the exception. Legitimate use: `contextlib.suppress(FileNotFoundError)`, or a retry helper that deliberately swallows a specific, expected exception.
8. `raise X from e` sets `X.__cause__ = e` (and `__suppress_context__ = True`); traceback says "direct cause". `raise X` inside `except` sets only `X.__context__` automatically; traceback says "During handling...". `raise X from None` sets `__cause__ = None` and `__suppress_context__ = True`; `__context__` still exists but is not displayed.
9. `KeyboardInterrupt`, `SystemExit` and `GeneratorExit` derive from `BaseException`, so `except Exception` skips them by design. `except Exception` belongs at a process or request boundary (log with traceback, convert to a response or exit code), or at a thread/job top level.
10. LBYL: `if os.path.exists(p): data = open(p).read()`; the file may be deleted between check and open. EAFP: `try: ... except FileNotFoundError:`. LBYL is better for cheap local validation of user input when failure is the common case (clear error messages before expensive work), or when a `try` would need to wrap too much code.
11. The function returns `1` and the `E` exception is discarded, because a `return` in `finally` overrides in-flight exceptions. Dangerous: hides real failures. Python 3.14 emits a `SyntaxWarning` for this (PEP 765, Final; confirmed in the 3.14 What's New).
12. No. `sorted` consumes the entire input and returns a list, so memory is O(n) at that stage. Reading and writing stream, but the pipeline as a whole does not.

## Section 8: Challenge reference solution

```python
# challenge.py
import os
import time
from collections.abc import Iterable, Iterator
from contextlib import contextmanager
from typing import Any


def chunks(iterable: Iterable[Any], size: int) -> Iterator[list[Any]]:
    """Validation happens at call time because chunks is NOT itself a generator."""
    if size < 1:
        raise ValueError("size must be >= 1")
    return _chunks(iter(iterable), size)


def _chunks(it: Iterator[Any], size: int) -> Iterator[list[Any]]:
    while True:
        chunk = []
        for _ in range(size):
            try:
                chunk.append(next(it))
            except StopIteration:
                break
        if not chunk:
            return
        yield chunk
        if len(chunk) < size:
            return


class Timer:
    def __init__(self, clock=time.monotonic):
        self._clock = clock
        self.elapsed = None
    def __enter__(self):
        self._start = self._clock()
        return self
    def __exit__(self, et, ev, tb):
        self.elapsed = self._clock() - self._start
        return False


@contextmanager
def temp_env(**new: str):
    missing = object()
    old = {k: os.environ.get(k, missing) for k in new}
    os.environ.update(new)
    try:
        yield
    finally:
        for k, v in old.items():
            if v is missing:
                os.environ.pop(k, None)
            else:
                os.environ[k] = v   # type: ignore[assignment]


class ReportError(Exception): ...
class InputError(ReportError): ...
class RenderError(ReportError): ...

def render(data: dict[str, str]) -> str:
    try:
        return f"{data['title']}: {data['body']}"
    except KeyError as exc:
        raise InputError(f"missing field {exc.args[0]!r}") from exc
```

```python
# test_challenge.py
import os, pytest
from challenge import chunks, Timer, temp_env, render, InputError

def test_chunks_basic():
    assert list(chunks([], 3)) == []
    assert list(chunks([1, 2], 5)) == [[1, 2]]
    assert list(chunks(range(7), 3)) == [[0, 1, 2], [3, 4, 5], [6]]

def test_chunks_validates_at_call_time():
    with pytest.raises(ValueError):
        chunks([1], 0)

def test_chunks_lazy_no_read_ahead():
    pulled = []
    def src():
        for i in range(10):
            pulled.append(i); yield i
    g = chunks(src(), 3)
    next(g)
    assert pulled == [0, 1, 2]

def test_timer_and_exception_not_suppressed():
    ticks = iter([1.0, 4.5])
    with pytest.raises(RuntimeError):
        with Timer(clock=lambda: next(ticks)) as t:
            raise RuntimeError
    assert t.elapsed == 3.5

def test_temp_env_restores():
    os.environ["EXISTING"] = "old"; os.environ.pop("ABSENT", None)
    with pytest.raises(RuntimeError):
        with temp_env(EXISTING="new", ABSENT="x"):
            assert os.environ["EXISTING"] == "new"
            raise RuntimeError
    assert os.environ["EXISTING"] == "old" and "ABSENT" not in os.environ

def test_render_cause():
    with pytest.raises(InputError) as ei:
        render({})
    assert isinstance(ei.value.__cause__, KeyError)
```

Trade-offs: `chunks` is a plain function returning an inner generator so validation is eager; a single generator function would raise only at first `next()`. `temp_env` uses a private sentinel so a variable set to `""` is distinguished from absent. Alternative for `temp_env`: `unittest.mock.patch.dict(os.environ, ...)`, which also restores state and is the usual answer in tests (Lesson 1.4); hand-writing it is the point of the exercise. `Timer` as a class is preferable to a generator-based manager here because it needs to expose `.elapsed` afterwards.

### Failure semantics table (for README)

| Situation | Behavior | Exit code (CLI wrapper, not shown) |
|---|---|---|
| Malformed JSON, missing key, bad type, bad timestamp | Record rejected, written to rejects file, run continues | 0 |
| Duplicate `id` | First wins; later rows ignored by `INSERT OR IGNORE`, counted in `ignored_duplicates` (not individually reported) | 0 |
| Reject ratio above threshold | `TooManyRejects`; completed batches stay committed; in-flight batch is not committed | 2 |
| `sqlite3.Error` on a batch | Batch rolled back; `StorageError` with `__cause__`; run aborts | 3 |
| Invalid UTF-8 | `UnicodeDecodeError` propagates and aborts the run (policy: input corruption is not a "bad record"); batches before it stay committed | 3 |
| Bad arguments | `ConfigError` before any I/O | 64 |

(Exit codes are a convention you choose; document them. The CLI wrapper is out of scope here.)

### DECISIONS.md (reference)

- **Duplicates.** Rely on `PRIMARY KEY(id)` and `INSERT OR IGNORE`. Memory is O(1) in the application. Cost: duplicates are counted via `conn.total_changes` deltas, not reported per row, and "first wins" is relative to what is already in the database, including earlier runs. If per-row duplicate reporting is required, the alternatives are an in-memory `set` of ids (O(n) memory, violates the constraint for huge files) or a temp table plus `INSERT ... SELECT` (extra I/O).
- **Invalid UTF-8.** Fail the run: it suggests the wrong file or corruption, and silently replacing characters would corrupt data. Alternative: open with `errors="replace"` and reject lines containing the replacement character; defensible for logs, not for payments.
- **Reject ratio.** 5% default is an arbitrary operational choice (confirm it with the data owner); it is checked at batch boundaries and at the end, so a run can read a few more rows than the threshold before aborting.
- **`total_changes` for counting.** I used the connection-level `total_changes` delta because `rowcount` semantics for `executemany` differ between drivers. Checked on Python 3.13 `sqlite3`: `executemany("insert or ignore ...")` of three rows with one duplicate gave `cursor.rowcount == 2` and a `total_changes` delta of 2, so either works for sqlite3; the delta is the more portable habit within sqlite3 because it also counts statements whose `rowcount` is -1.

```python
# src/ingest/errors.py
class IngestError(Exception):
    """Root of every error this package raises deliberately."""


class BadRecord(IngestError):
    def __init__(self, line_no: int, reason: str, raw: str = "") -> None:
        super().__init__(f"line {line_no}: {reason}")
        self.line_no = line_no
        self.reason = reason
        self.raw_excerpt = raw[:200]


class StorageError(IngestError):
    """The database refused a batch."""


class ConfigError(IngestError):
    """Invalid arguments (batch size, ratio)."""


class TooManyRejects(IngestError):
    """Reject ratio exceeded; earlier batches stay committed, the in-flight batch is not."""
```

```python
# src/ingest/core.py
from __future__ import annotations

import json
import sqlite3
from collections.abc import Callable, Iterable, Iterator
from contextlib import ExitStack, contextmanager
from dataclasses import dataclass
from datetime import datetime
from itertools import batched
from pathlib import Path

from .errors import BadRecord, ConfigError, StorageError, TooManyRejects

Row = tuple[str, str, int, str]

SCHEMA = """CREATE TABLE IF NOT EXISTS payments(
    id TEXT PRIMARY KEY, user TEXT NOT NULL, amount_cents INTEGER NOT NULL, ts TEXT NOT NULL)"""


@dataclass
class Summary:
    read: int = 0
    loaded: int = 0
    rejected: int = 0
    ignored_duplicates: int = 0
    batches: int = 0


def read_lines(lines: Iterable[str]) -> Iterator[tuple[int, str]]:
    for line_no, line in enumerate(lines, start=1):
        if line.strip():
            yield line_no, line


def _validate(obj: object) -> Row:
    if not isinstance(obj, dict):
        raise ValueError("record is not an object")
    try:
        rid, user, amount, ts = obj["id"], obj["user"], obj["amount_cents"], obj["ts"]
    except KeyError as exc:
        raise ValueError(f"missing key {exc.args[0]!r}") from exc
    if not isinstance(rid, str) or not rid:
        raise ValueError("id must be a non-empty string")
    if not isinstance(user, str):
        raise ValueError("user must be a string")
    if isinstance(amount, bool) or not isinstance(amount, int) or amount < 0:
        raise ValueError("amount_cents must be an int >= 0")
    if not isinstance(ts, str):
        raise ValueError("ts must be a string")
    datetime.fromisoformat(ts)  # ValueError if invalid
    return rid, user, amount, ts


def parse(lines: Iterable[tuple[int, str]], on_reject: Callable[[BadRecord], None],
          summary: Summary | None = None) -> Iterator[Row]:
    for line_no, line in lines:
        if summary:
            summary.read += 1
        try:
            row = _validate(json.loads(line))
        except ValueError as exc:  # JSONDecodeError is a ValueError subclass
            on_reject(BadRecord(line_no, f"{type(exc).__name__}: {exc}", line))
            if summary:
                summary.rejected += 1
            continue
        yield row


@contextmanager
def transaction(conn: sqlite3.Connection) -> Iterator[sqlite3.Connection]:
    try:
        yield conn
    except BaseException:
        conn.rollback()
        raise
    else:
        conn.commit()


def _insert_batch(conn: sqlite3.Connection, batch: tuple[Row, ...]) -> int:
    before = conn.total_changes
    try:
        with transaction(conn):
            conn.executemany("INSERT OR IGNORE INTO payments VALUES (?, ?, ?, ?)", batch)
    except sqlite3.Error as exc:
        raise StorageError(f"batch of {len(batch)} failed") from exc
    return conn.total_changes - before


def run(path: Path, db_path: str, batch_size: int = 1000, max_reject_ratio: float = 0.05,
        rejects_path: Path | None = None) -> Summary:
    if batch_size < 1 or not 0 <= max_reject_ratio <= 1:
        raise ConfigError("batch_size must be >= 1 and max_reject_ratio within [0, 1]")
    summary = Summary()
    with ExitStack() as stack:
        src = stack.enter_context(path.open(encoding="utf-8", errors="strict"))
        conn = stack.enter_context(_closing(sqlite3.connect(db_path)))
        out = stack.enter_context(rejects_path.open("w", encoding="utf-8")) if rejects_path else None

        def on_reject(rec: BadRecord) -> None:
            if out:
                out.write(json.dumps({"line": rec.line_no, "reason": rec.reason,
                                      "raw": rec.raw_excerpt}) + "\n")

        try:
            conn.execute(SCHEMA)
        except sqlite3.Error as exc:
            raise StorageError("cannot create schema") from exc
        rows = parse(read_lines(src), on_reject, summary)
        for batch in batched(rows, batch_size):
            # the parse stage has already advanced `read`/`rejected` for this batch
            if summary.read and summary.rejected / summary.read > max_reject_ratio:
                raise TooManyRejects(f"{summary.rejected}/{summary.read} rejected")
            inserted = _insert_batch(conn, batch)
            summary.loaded += inserted
            summary.ignored_duplicates += len(batch) - inserted
            summary.batches += 1
        if summary.read and summary.rejected / summary.read > max_reject_ratio:
            raise TooManyRejects(f"{summary.rejected}/{summary.read} rejected")
    return summary


@contextmanager
def _closing(conn: sqlite3.Connection) -> Iterator[sqlite3.Connection]:
    try:
        yield conn
    finally:
        conn.close()
```

```python
# tests/test_ingest.py
import json, sqlite3, tracemalloc
import pytest
from ingest import run, parse, read_lines, transaction, TooManyRejects, StorageError, ConfigError, BadRecord
from ingest import core

def rec(i, **kw):
    d = {"id": f"id{i}", "user": "u", "amount_cents": i, "ts": "2024-01-01T00:00:00"}
    d.update(kw); return json.dumps(d)

def write(p, lines): p.write_text("\n".join(lines) + "\n"); return p

def test_parse_stage_alone_with_list_input():
    rejects = []
    lines = [(1, rec(1)), (2, "not json"), (3, rec(3, amount_cents=True)), (4, rec(4, amount_cents=1.5)),
             (5, rec(5, ts="nope")), (6, '{"id": "x"}')]
    rows = list(parse(lines, rejects.append))
    assert len(rows) == 1 and [r.line_no for r in rejects] == [2, 3, 4, 5, 6]

def test_run_happy_path_and_rejects_file(tmp_path):
    p = write(tmp_path / "in.ndjson", [rec(1), "bad", rec(2), rec(2), rec(3)])
    s = run(p, str(tmp_path / "db.sqlite"), batch_size=2, max_reject_ratio=0.5, rejects_path=tmp_path / "rej.ndjson")
    assert (s.read, s.loaded, s.rejected, s.ignored_duplicates) == (5, 3, 1, 1)
    rej = [json.loads(l) for l in (tmp_path / "rej.ndjson").read_text().splitlines()]
    assert rej[0]["line"] == 2 and "JSONDecodeError" in rej[0]["reason"]

def test_empty_file_no_division_by_zero(tmp_path):
    p = tmp_path / "e.ndjson"; p.write_text("")
    assert run(p, str(tmp_path / "d.db")).read == 0

def test_no_trailing_newline_crlf_blank_lines(tmp_path):
    p = tmp_path / "x.ndjson"; p.write_bytes((rec(1) + "\r\n\r\n" + rec(2)).encode())
    assert run(p, str(tmp_path / "d.db")).loaded == 2

def test_too_many_rejects_keeps_earlier_batches(tmp_path):
    lines = [rec(i) for i in range(4)] + ["bad"] * 6 + [rec(100)]
    p = write(tmp_path / "in.ndjson", lines)
    with pytest.raises(TooManyRejects):
        run(p, str(tmp_path / "d.db"), batch_size=2, max_reject_ratio=0.2)
    n = sqlite3.connect(tmp_path / "d.db").execute("SELECT count(*) FROM payments").fetchone()[0]
    assert n % 2 == 0 and n < 5   # only whole batches committed

def test_storage_error_rolls_back_batch_and_chains(tmp_path, monkeypatch):
    p = write(tmp_path / "in.ndjson", [rec(i) for i in range(4)])
    real = core._insert_batch
    calls = {"n": 0}
    def flaky(conn, batch):
        calls["n"] += 1
        if calls["n"] == 2:
            conn.execute("INSERT INTO payments VALUES ('half','u',1,'2024-01-01')")  # uncommitted write
            raise StorageError("boom")
        return real(conn, batch)
    monkeypatch.setattr(core, "_insert_batch", flaky)
    with pytest.raises(StorageError):
        run(p, str(tmp_path / "d.db"), batch_size=2)
    ids = [r[0] for r in sqlite3.connect(tmp_path / "d.db").execute("SELECT id FROM payments")]
    assert sorted(ids) == ["id0", "id1"]   # connection closed without commit -> 'half' discarded

def test_sqlite_error_is_chained():
    conn = sqlite3.connect(":memory:")   # no table
    with pytest.raises(StorageError) as ei:
        core._insert_batch(conn, (("a", "u", 1, "2024-01-01"),))
    assert isinstance(ei.value.__cause__, sqlite3.OperationalError)

def test_transaction_rolls_back():
    conn = sqlite3.connect(":memory:"); conn.execute("CREATE TABLE t(x)"); conn.commit()
    with pytest.raises(RuntimeError):
        with transaction(conn):
            conn.execute("INSERT INTO t VALUES (1)"); raise RuntimeError
    assert conn.execute("SELECT count(*) FROM t").fetchone()[0] == 0

def test_config_errors(tmp_path):
    with pytest.raises(ConfigError): run(tmp_path / "x", "d", batch_size=0)

def test_invalid_utf8_fails_run_and_closes(tmp_path):
    p = tmp_path / "b.ndjson"; p.write_bytes(b"\xff\xfe\n")
    with pytest.raises(UnicodeDecodeError): run(p, str(tmp_path / "d.db"))   # documented policy: fail the run

def test_memory_does_not_scale_with_input(tmp_path):
    def peak(n):
        p = tmp_path / f"{n}.ndjson"
        p.write_text("".join(rec(i) + "\n" for i in range(n)))
        tracemalloc.start()
        run(p, str(tmp_path / f"{n}.db"), batch_size=500)
        _, pk = tracemalloc.get_traced_memory(); tracemalloc.stop()
        return pk
    small, large = peak(2_000), peak(20_000)
    assert large < small * 3
```

Notes on the tests: `test_storage_error_rolls_back_batch_and_chains` uses `monkeypatch` to inject a failing batch (Lesson 1.4 explains why this is acceptable here: it replaces a collaborator at its use site). The memory test compares two sizes with a loose factor rather than asserting an absolute number; the factor 3 for a 10x size increase is a judgement call, and you should look at your own measured numbers before choosing it. The "input closed after mid-pipeline failure" criterion is covered indirectly by `ExitStack` in `run`; a stricter test passes a recording file-like object (the project allows either).

### Alternative approaches

- Yield `Ok`/`Err` tagged values instead of a callback for rejects; cleaner data flow, more types.
- `csv.DictReader` input; same shape, but note `csv` field values are all strings so validation becomes conversion.
- One transaction for the whole file (all-or-nothing). Simpler semantics, but a long write lock and a single failure discards hours of work; batch commits plus idempotent `INSERT OR IGNORE` makes the job safely re-runnable, which is usually the better operational property.
